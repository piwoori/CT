# [silver 5] 크로아티아 알파벳 - 2941

[문제 링크](https://www.acmicpc.net/problem/2941)

### 분류
- 배열
- 반복문

### 문제 요약
- 크로아티아 알파벳 소문자와 '-', '='로만 이루어져 있는 최대 100글자의 단어 입력
- "č: c= ", " ć	= c-", "dž : dz=", "đ : d-", " lj : lj", "nj : nj", "š : s=", "ž : z=" 적용
- dž는 무조건 하나의 알파벳으로 쓰이고, d와 ž가 분리된 것으로 보지 않음
- 몇 개의 크로아티아 알파벳으로 이루어져 있는지 출력


### 풀이 아이디어
- 크로아티아 알파벳으로 이루어져있는 배열 선언
- contatins() 이용해 해당 문자는 다른 단어(예 - #)로 바꿔놓음
- length 이용해 갯수 출력

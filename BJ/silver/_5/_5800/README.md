# [silver 5] 성적 통계 - 5800

[문제 링크](https://www.acmicpc.net/problem/5800)

### 분류
- 조건문
- 반복문
- 배열
- 내림차순 정렬

### 문제 요약
- 고등학교에 있는 반의 수 K 입력
- 각 줄에는 각 반의 학생수 N (2 ≤ N ≤ 50)과 각 학생의 수학 성적(0 이상 100 이하) 입력
- 첫째 줄에는 반의 번호이자 입력으로 주어진 순서대로 1부터 증가된  "Class X"를 출력
- 둘째 줄에는 가장 높은 점수, 낮은 점수, 성적을 내림차순으로 정렬했을 때 가장 큰 인접한 점수 차이를 "Max 78, Min 23, Largest gap 46"과 같은 형식으로 출력

### 풀이 아이디어
- 배열 선언 시 int가 아닌 Integer로 초기화
- Arrays.sort(list, Comparator.reverseOrder()) 이용해 내림차순 정렬

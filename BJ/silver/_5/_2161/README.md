# [silver 5] 카드 1 - 2161

[문제 링크](https://www.acmicpc.net/problem/2161)

### 분류
- 큐

### 문제 요약
- 정수 N(1 ≤ N ≤ 1,000) 입력
- 1번 카드가 제일 위에, N번 카드가 제일 아래인 상태로 순서대로 카드가 놓여 있음
- 제일 위에 있는 카드를 바닥에 버리고 제일 위에 있는 카드를 제일 아래에 있는 카드 밑으로 옮기기 반복
- 버린 카드들을 순서대로 출력하고, 마지막에 남게 되는 카드를 출력

### 풀이 아이디어
- queue 이용
- .add(), .poll() 함수 이용

# [silver 5] 덩치 - 7568

[문제 링크](https://www.acmicpc.net/problem/7568)

### 분류
- 조건문
- 반복문
- 2차원 배열

### 문제 요약
- 전체 사람의 수 N 입력
- 사람의 몸무게와 키를 나타내는 양의 정수 x와 y 입력
- A 와 B의 덩치가 각각 (x, y), (p, q)라고 할 때 x > p && y > q 일 때: A의 덩치가 B의 덩치보다 "더 큼"
- 덩치 등수는 자신보다 더 "큰 덩치"의 사람의 수로 정해짐
- 자신보다 더 큰 덩치의 사람이 k명이라면 그 사람의 덩치 등수는 k+1이 됨(같은 등수 가능)
- 공백을 두고 각 덩치 등수 출력

### 풀이 아이디어
- 2차원 배열 [][] 이용
- 이중 반복문 이용

# [silver 5] k번 째 수 - 11004

[문제 링크](https://www.acmicpc.net/problem/11004)

### 분류
- 리스트
- BufferedReader
- StringTokenizer

### 문제 요약
- N(1 ≤ N ≤ 5,000,000)과 K (1 ≤ K ≤ N) 입력
- N개를 오름차순으로 정렬 후 K번째 있는 수 출력

### 풀이 아이디어
- BufferedReader 이용
- StringTokenizer 이용
- Integer.parseInt(st.nextToken())으로 하나씩 빼서 사용

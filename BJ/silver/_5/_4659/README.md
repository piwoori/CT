# [silver 5] 비밀번호 발음하기 - 4659

[문제 링크](https://www.acmicpc.net/problem/4659)

### 분류
- 조건문
- 반복문

### 문제 요약
- 한글자 이상 20글자 이하의 문자열의 패스워드 입력
- 모음(a,e,i,o,u) 하나를 반드시 포함, 모음이 3개 혹은 자음이 3개 연속으로 오면 안 됨, 같은 글자가 연속적으로 두번 오면 안되나, ee 와 oo는 허용
- 위와 같은 조건 만족 시 "<패스워드> is acceptable." 출력
- 아닐 시 "<패스워드> is not acceptable." 출력

### 풀이 아이디어
- while문의 조건식 문자열.equals 이용
- 연속 판단할 때, 자음이면 모음 0 초기화, 모음이면 자음 0 초기화

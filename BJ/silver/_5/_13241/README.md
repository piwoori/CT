# [silver 5] 최소공배수 - 13241

[문제 링크](https://www.acmicpc.net/problem/13241)

### 분류
- 반복문
- 조건문
- 함수

### 문제 요약
- 정수 A, B 입력
- 50%의 입력 중 A와 B는 1000(103)보다 작음
- 다른 50%의 입력은 1000보다 크고 100000000(108)보다 작음
- A는 B의 배수
- 최소공배수 출력

### 풀이 아이디어
- Main 밖에서 static 함수 선언
- 최대공약수: 유클리드 호제법(나머지가 0이 될 때까지 두 수를 계속 나눔) 이용
- 최소공배수: 두 수를 곱한 값을 최대공약수로 나눔
- 함수를 static(객체 없어도 쓸 수 있게 만듦)으로 선언했으면, 함수 쓰기 전에 초기화? 안 해도 됨

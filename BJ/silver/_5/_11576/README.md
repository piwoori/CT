# [silver 5] Base Conversion - 11576

[문제 링크](https://www.acmicpc.net/problem/11576)

### 분류
- 조건문
- 스택
- 진법

### 문제 요약
- 미래세계에서 사용하는 진법 A와 정이가 사용하는 진법 B 공백 구분으로 입력(2 <= A, B <= 30)
- A진법으로 나타낸 숫자의 자리수의 개수 m(1 ≤ m ≤ 25) 입력
- A진법을 이루고 있는 숫자 m개가 공백을 구분으로 높은 자릿수부터 입력 (0 <= m < A)
- 입력으로 주어진 A진법으로 나타낸 수를 B진법으로 변환하여 출력

### 풀이 아이디어
- Math.pow 함수 이용해 A 진법 수들을 10진법으로 변환
- stack.push(sum % B), sum /= B; 으로 10진법을 B진법으로 변환
- 스택 이용해 역순으로 출력

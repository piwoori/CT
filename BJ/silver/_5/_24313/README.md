# [silver 5] 알고리즘 수업 - 점근적 표기 1 - 24313

[문제 링크](https://www.acmicpc.net/problem/24313)

### 분류
- 조건문

### 문제 요약
- 함수 f(n)을 나타내는 정수 a1, a0 입력 (0 ≤ |ai| ≤ 100)
- 양의 정수 c 입력 (1 ≤ c ≤ 100)
- 양의 정수 n0 입력 (1 ≤ n0 ≤ 100)
- f(n), c, n0가 O(n) 정의를 만족하면 1, 아니면 0을 출력

### 풀이 아이디어
- a1 * n0 + a0 <= c * n0 식에서 a1 <= c 조건 추가

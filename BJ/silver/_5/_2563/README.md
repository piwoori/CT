# [silver 5] 색종이 - 2563

[문제 링크](https://www.acmicpc.net/problem/2563)

### 분류
- 이차원 배열
- 반복문

### 문제 요약
- 100 이하의 색종이의 수 입력
- 가로, 세로의 크기가 각각 100인 정사각형 모양의 흰색 도화지 존재
- 둘째 줄부터 한 줄에 하나씩 색종이를 붙인 위치 입력(도화지 범위를 넘어가지 않음)
- 정사각형 모양의 검은색 색종이를 색종이의 변과 도화지의 변이 평행하도록 붙임
- 이러한 방식으로 색종이를 한 장 또는 여러 장 붙인 후 색종이가 붙은 검은 영역의 넓이 출력

### 풀이 아이디어
- [100][100] 크기의 이차원 배열 설정
- 색종이 크기의 영역을 1로 변경
- 1인 개수 다 구하기

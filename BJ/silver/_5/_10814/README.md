# [silver 5] 나이순 정렬- 10814

[문제 링크](https://www.acmicpc.net/problem/10814)

### 분류
- 클래스
- 람다

### 문제 요약
- 첫째 줄에 온라인 저지 회원의 수 N 입력(1 ≤ N ≤ 100,000)
- 둘째 줄부터 N개의 줄에는 각 회원의 나이와 이름이 공백으로 구분되어 입력
- 나이는 1보다 크거나 같으며, 200보다 작거나 같은 정수
- 이름은 알파벳 대소문자로 이루어져 있고, 길이가 100보다 작거나 같은 문자열
- 첫째 줄부터 총 N개의 줄에 걸쳐 온라인 저지 회원을 나이 순, 나이가 같으면 가입한 순으로 한 줄에 한 명씩 나이와 이름을 공백으로 구분해 출력

### 풀이 아이디어
- 정수와 문자열을 한 꺼번에 다루기 위해 Person 클래스 별로도 정의
- 반복문과 BufferedReader,  StringTokenizer 이용해 입력 받고 배열 arr에 저장
- Arrays.sort(arr, (a, b) -> a.age - b.age)의 람다식 실행
- StringBuilder로 빠르게 출력

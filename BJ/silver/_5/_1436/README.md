# [silver 5] 영화감독 숌 - 1436

[문제 링크](https://www.acmicpc.net/problem/1436)

### 분류
- 조건문
- 반복문

### 문제 요약
- 종말의 수(666)가 들어간 수 중 N번째의 종말의 수의 N 입력(10,000보다 작거나 같은 수)
- 제일 작은 종말의 수는 666이고, 그 다음으로 큰 수는 1666, 2666, 3666, ....
- N번째 영화의 제목이 들어간 수 출력

### 풀이 아이디어
- while 반복문 이용
- count와 number 변수 선언 이용
- number 1씩 증가 시키는 반복문 실행
- count가 N이 되면 반복문 중단
- String.valueOf(number).contains("666") 이용해 666이 들어가면 count 증가

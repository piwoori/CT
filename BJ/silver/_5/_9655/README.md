# [silver 5] 돌 게임 1 - 9655

[문제 링크](https://www.acmicpc.net/problem/9655)

### 분류
- 조건문

### 문제 요약
- 돌의 수 N 입력(1 이상 1000 이하)
- 근이와 창영이는 턴을 번갈아가면서 돌을 가져감
- 돌은 1개 또는 3개 가져갈 수 있으며 마지막 돌을 가져가는 사람이 게임을 짐
- 상근이가 먼저 시작할 때 근이가 게임을 이기면 SK를, 영이가 게임을 이기면 CY을 출력

### 풀이 아이디어
- 나머지 연산자 연산자 이용
- Bufferedreader, Bufferedwriter 이용

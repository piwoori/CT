# [silver 5] 그룹 단어 체커 - 1316

[문제 링크](https://www.acmicpc.net/problem/1316)

### 분류
- 조건문
- 반복문
- 배열

### 문제 요약
- 단어의 개수 N(100보다 작거나 같은 자연수) 입력
- N개의 줄에 소문자로만 되어있는 중복 없는 단어  입력
- 그룹 단어: 각 문자가 연속해서 나타나는 경우를 의미
- 같은 문자가 떨어져있음 안 됨
- 그룹 단어의 개수 출력

### 풀이 아이디어
- 알파벳 개수 크기의 boolean 배열 이용
- s.charAt(j) != s.charAt(j - 1) 조건식 이용

# [silver 5] 단어 정렬 - 1181

[문제 링크](https://www.acmicpc.net/problem/1181)

### 분류
- Set
- List

### 문제 요약
- 첫째 줄에 단어의 개수 N 입력(1 ≤ N ≤ 20,000)
- 둘째 줄부터 N개의 줄에 걸쳐 알파벳 소문자로 이루어진 단어가 한 줄에 하나씩 입력(길이가 50 이하)
- 길이가 짧은 것부터, 길이가 같으면 사전 순으로, 중복된 단어는 하나만 남기고 제거
- 조건에 따라 정렬하여 단어들을 한 줄씩 출력

### 풀이 아이디어
- 중복 제거를 위해 Set 초기화
- 그 후 Set을 List로 초기화
- list.sort((a, b) ->의 람다식 실행
- a.length() == b.length() 이면 a.compareTo(b) 리턴
- 그 외는 a.length() - b.length() 리턴
- 반복문 이용해 출력

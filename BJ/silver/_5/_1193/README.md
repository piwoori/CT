# [silver 5] 분수 찾기 - 1193

[문제 링크](https://www.acmicpc.net/problem/1193)

### 분류
- 규칙

### 문제 요약
- 무한히 큰 배열에 1/1 → 1/2 → 2/1 → 3/1 → 2/2 → 1/3 → 1/4 → 2/3 → 3/2 → 4/1 … 과 같이 분수들이 나열 되어 있음
- 지그재그 순서로 차례대로 1번, 2번, 3번, 4번, 5번, … 분수라고 할 때 
- X번째 분수 출력

### 풀이 아이디어
- 분수는 대각선 단위로 증가
- 입력값 N이 몇 번째 대각선(floor)에 위치하는지 구하기 위해 N에서 1, 2, 3, ... 순서로 빼면서 floor를 증가
- 그 뒤 floor → N이 속한 대각선 번호, N → 해당 대각선에서의 위치 (몇 번째 칸)
- 해당 대각선의 분자와 분모의 합은 항상 일정
- 짝수 대각선일 때는 위 → 아래 방향, 분자 감소 및 분모 증가
- 홀수 대각선일 때는 아래 → 위 방향, 분자 증가 및 분모 감소

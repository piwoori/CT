# [silver 5] 셀프 넘버 - 4673

[문제 링크](https://www.acmicpc.net/problem/4673)

### 분류
- 함수
- 반복문

### 문제 요약
- 함수 d(n) = n + (n의 각 자리수 합) 을 정의
- 셀프 넘버(Self Number): 어떤 수 x 가 d(n)=x 를 만족하는 생성자 n 이 하나도 없을 때의 x
- 1부터 10000까지 범위에서, 생성자가 없는 수(셀프 넘버)만 오름차순으로 한 줄에 하나씩 출력

### 풀이 아이디어
- 1부터 10000까지 각 수에 대해 d(n)을 계산해 생성되는 수를 체크
- 생성된 수는 boolean 배열에 true로 표시하여 셀프 넘버가 아님을 구분
- self() 함수는 숫자 자체와 각 자리수를 더해 d(n)을 계산
- 다시 1부터 10000까지 순회하며 한 번도 생성되지 않은 수만 출력

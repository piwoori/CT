# [silver 5] 막대기 - 1094

[문제 링크](https://www.acmicpc.net/problem/1094)

### 분류
- 조건문
- 반복문

### 문제 요약
- 막대를 붙여 만들고 싶은 길이의 64보다 작거나 같은 자연수 X 입력
- 처음엔 64cm 막대이고 붙인 막대의 합이 X보다 크다면,
- 가지고 있는 막대 중 길이가 가장 짧은 것을 절반으로 자름
- 만약, 위에서 자른 막대의 절반 중 하나를 버리고 남아있는 막대의 길이의 합이 X보다 크거나 같다면, 위에서 자른 막대의 절반 중 하나를 버림
- 위의 방법을 반복하고 남아있는 모든 막대를 풀로 붙여 X 길이로 만듦
- 총 몇 개의 막대의 수가 필요한지 출력

### 풀이 아이디어
- 반복문으로 /= 2 적용 시키다가 X보다 짧아지면 더하기

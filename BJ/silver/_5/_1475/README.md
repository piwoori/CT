# [silver 5] 방 번호 - 1475

[문제 링크](https://www.acmicpc.net/problem/1475)

### 분류
- 조건문
- 반복문
- 문자열

### 문제 요약
- 다솜이의 방 번호 1,000,000보다 작거나 같은 자연수 N 입력
- 한 세트에는 0번부터 9번까지 숫자가 들어있을 때 방 번호를 만드는데 총 몇 세트가 필요한지 출력
- 6과 9는 동일한 수로 판단

### 풀이 아이디어
- 10개 크기의 배열 이용
- 문자열로 입력 받은 뒤 str.charAt() - '0' 이용해 인수로 변환
- 6은 9 배열 증가시키기
- arr[9] = arr[9] / 2 + arr[9] % 2 로 9 다시 정리
- .sort() 이용해 오름차순 정렬 
- 9번째 요소 출력()

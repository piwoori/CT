# [silver 4] 설탕 배달 - 2839

[문제 링크](https://www.acmicpc.net/problem/2839)

### 분류
- 경우의 수

### 문제 요약
- 배탈해야 할 설탕의 무게 정수 N 입력(3 ≤ N ≤ 5000)
- 3킬로그램 봉지와 5킬로그램 봉지가 있을 때
- 봉지 몇 개를 가져가면 되는지 최소한의 봉지 수 출력

### 풀이 아이디어
- n 이 4 또는 7 인 경우
- n 이 5의 배수인경우 ( 5로 나눈 나머지가 0 인 경우 )
- n 이 5의 배수 + 1 또는 5의 배수 + 3 인 경우 ( 5로 나눈 나머지가 1 또는 3 인 경우 )
- n 이 5의 배수 + 2 또는 5의 배수 + 4 인 경우 ( 5로 나눈 나머지가 2 또는 4 인 경우 )로 나눠 풀이

# [silver 4] 다음 소수 - 4134

[문제 링크](https://www.acmicpc.net/problem/4134)

### 분류
- 소수 판별

### 문제 요약
- 테스트 케이스 T 입력
- 각 줄에 정수 n(0 ≤ n ≤ 4*109) 입력
- n보다 크거나 같은 소수 중 가장 작은 소수 한 줄에 하나씩 출력

### 풀이 아이디어
- long 변수로 입력 받기
- N이 1 이하 일 땐 2 출력
- 2 이상 N 이하의 제곱근까지 반복문 이용
- N이 long 형이니까 제곱근 표현할 때도 long 형으로 변환 필수
- 조건식 수로 나눠떨어지면 count 증가
- count 0 일 때 소수인 거로 판별 및 반복문 종료
- N 증가시켜 반복

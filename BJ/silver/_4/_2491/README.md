# [silver 4] 수열 - 2491

[문제 링크](https://www.acmicpc.net/problem/2491)

### 분류
- 수열
- 배열

### 문제 요약
- 1 이상 100,000 이하의 정수인 수열의 길이 N 입력
- 둘째 줄에는 N개의 숫자가 빈칸을 사이에 두고 입력
- 그 수열 안에서 연속해서 커지거나(같은 것 포함), 혹은 연속해서 작아지는(같은 것 포함) 수열 중 가장 길이가 긴 것 출력

### 풀이 아이디어
- 수열의 길이가 1일 때는 1 출력
- incLen , decLen, maxLen을 1로 초기화
- N번의 반복문 안에서 증가 수열일 때와 감소 수열일 때로 분기
- i가 i-1보다 증가되거나 감소되면 incLen , decLen 1씩 증가
- 그렇지 않으면 incLen , decLen 다시 1로 초기화
- 각 원소 비교할 때마다 incLen , decLen, maxLen 세 개의 값 비교헤 제일 큰 값 maxLen에 저장

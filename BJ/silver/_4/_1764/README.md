# [silver 4] 듣보잡 - 1764

[문제 링크](https://www.acmicpc.net/problem/1764)

### 분류
- HashSet
- ArrayList

### 문제 요약
- 듣도 못한 사람의 수 N, 보도 못한 사람의 수 M 입력(N, M은 500,000 이하의 자연수)
- 둘째 줄부터 N개의 줄에 걸쳐 듣도 못한 사람의 이름과, N+2째 줄부터 보도 못한 사람의 이름이 순서대로 입력
- 이름은 띄어쓰기 없이 알파벳 소문자로만 이루어지며, 그 길이는 20 이하
- 듣보잡의 수와 그 명단을 사전순으로 출력

### 풀이 아이디어
- 처음 N개의 이름을 HashSet에 저장
- HashSet: 중복 저장 X, 저장 순서 없음, 검색 속도 빠름
- contains() 이용해 보잡의 이름이 저장되어있는지 확인 
- Collections.sort() 이용

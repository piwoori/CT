# [silver 4] 한수 - 1065

[문제 링크](https://www.acmicpc.net/problem/1065)

### 분류
- 등차수열

### 문제 요약
- 첫째 줄에 1,000보다 작거나 같은 자연수 N 입력
- 어떤 양의 정수 X의 각 자리가 등차수열을 이룬다면, 그 수를 한수라고 함
- N이 주어졌을 때, 1보다 크거나 같고, N보다 작거나 같은 한수의 개수를 출력

### 풀이 아이디어
- 1부터 N까지 모든 수를 하나씩 검사
- 수가 100 미만이면 무조건 한수로 카운트
- 수가 100 이상이면 각 자릿수 분리하고 연속된 자릿수의 차이가 모두 같으면 한수(최소 99)로 카운트

# [silver 4] 차집합 - 1822

[문제 링크](https://www.acmicpc.net/problem/1822)

### 분류
- 자료 구조
- 정렬
- 이진 탐색 트리

### 문제 요약
- 집합 A의 원소의 개수 n(A)와 집합 B의 원소의 개수 n(B)가 빈 칸을 사이에 두고 입력
- 둘째 줄에는 집합 A의 원소가, 셋째 줄에는 집합 B의 원소가 빈 칸을 사이에 두고 입력
- 집합의 원소는 2,147,483,647 이하의 자연수
- 집합 A에는 속하면서 집합 B에는 속하지 않는 모든 원소의 개수 출력(없다면 0 출력)
- 다음 줄에는 구체적인 원소를 빈 칸을 사이에 두고 증가하는 순서로 출력

### 풀이 아이디어
- Treeset(중복 허용 안 함/원소 자동으로 오름차순 정렬) 이용
- A를 set에 넣고, B를 읽으면서 set에서 remove하면 남는 게 A−B
- StringBuilder(매번 새로운 객체 생성 없이 하나의 객체에 문자열 계속 추가) 이용

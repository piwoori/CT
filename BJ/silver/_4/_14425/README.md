# [silver 4] 문자열 집합 - 14425

[문제 링크](https://www.acmicpc.net/problem/14425)

### 분류
- ArrayList

### 문제 요약
- 문자열의 개수 N과 M (1 ≤ N ≤ 10,000, 1 ≤ M ≤ 10,000) 입력
- 다음 N개의 줄에는 집합 S에 포함되어 있는 문자열 입력
- 다음 M개의 줄에는 검사해야 하는 문자열 입력
- 입력으로 주어지는 문자열은 알파벳 소문자로만 이루어져 있으며, 길이는 500을 넘지 않고 중복 없음
- 입력으로 주어지는 M개의 문자열 중에서 집합 S에 포함되어 있는 것이 총 몇 개인지 출력

### 풀이 아이디어
- ArrayList 이용
- .contains() 이용

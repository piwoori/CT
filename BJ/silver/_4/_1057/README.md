# [silver 4] 토너먼트 - 1057

[문제 링크](https://www.acmicpc.net/problem/1057)

### 분류
- 반복문

### 문제 요약
- 토너먼트 참가자 수 N(2 ≤ N ≤ 1,000,000)과 김지민과 임한수의 참가 번호 입력
- 서로 인접한 번호끼리 스타 후 이긴사람은 다음 라운드 진출하며, 다시 참가자의 번호를 1번부터 매김
- 김지민과 임한수가 대결하는 라운드 번호를 출력
- 만약 서로 대결하지 않을 때는 -1을 출력

### 풀이 아이디어
- (홀수 번호인 경우: 현재 번호 / 1 == 짝수 번호인 경우: 현재 번호 / 2) 이 경우에 스타를 함께 하게 됨
- 토너먼트 방식이므로 -1이 출력되는 경우는 없음

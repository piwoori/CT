# [silver 4] 제로 - 10773

[문제 링크](https://www.acmicpc.net/problem/10773)

### 분류
- 스택

### 문제 요약
- 장부에 적을 돈의 개수 정수 K (1 ≤ K ≤ 100,000) 입력
- 이후 K개의 줄에 정수가 1개씩 입력 (0에서 1,000,000 사이의 값)
- 정수가 "0" 일 경우에는 가장 최근에 쓴 수를 지우고, 아닐 경우 해당 수를 씀
- 최종적으로 적어 낸 수의 합을 출력 (231-1보다 작거나 같은 정수)

### 풀이 아이디어
- Stack 이용
- pop() push() 이용

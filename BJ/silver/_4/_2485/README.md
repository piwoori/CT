# [silver 4] 가로수 - 2485

[문제 링크](https://www.acmicpc.net/problem/2485)

### 분류
- 최소공약수

### 문제 요약
- 이미 심어져 있는 가로수의 수를 나타내는 하나의 정수 N 입력(3 ≤ N ≤ 100,000)
- 각 줄마다 심어져 있는 양의 정수 가로수의 위치(기준점으로부터 떨어진 거리가 가까운 순) 입력
- 모든 가로수가 같은 간격이 되도록 새로 심어야 하는 가로수의 최소수를 첫 번째 줄에 출력

### 풀이 아이디어
- 위치 배열에 저장
- 앞 뒤 위치의 간격 구한 뒤 최소공약수 함수 적용해 최소공약수 갱신
- 맨 앞 위치 -  맨 뒤 위치 / 최소 공배수 + 1으로 총 가로수 수 계산
- 총 가로수 - 이미 심어져있는 가로수 N으로 최종 계산

# [silver 4] 균형잡힌 세상 - 4949

[문제 링크](https://www.acmicpc.net/problem/4949)

### 분류
- 스택

### 문제 요약
- 마지막 글자를 제외하고 영문 알파벳, 공백, 소괄호("( )"), 대괄호("[ ]")로 이루어져 있는 문자열 입력
- 온점(".")으로 끝나고, 길이는 100글자보다 작거나 같음
- 입력의 종료조건으로 맨 마지막에 온점 하나(".") 입력
- 문자열에 포함되는 괄호는 소괄호("()") 와 대괄호("[]")로 2종류
- 모든 괄호는 짝을 이루면 균형을 이룬다고 봄
- 각 줄마다 해당 문자열이 균형을 이루고 있으면 "yes"를, 아니면 "no"를 출력

### 풀이 아이디어
- Stack 이용
- pop() push() peek() 이용
- '(', '[' 일 때와 아닐 때를 나눠 진행
- ')'과 ']'일 때, 스택이 비었을 때는 push(), 비어져있지 않을 때는 pop() 진행

# [silver 4] 대칭 차집합 - 1269

[문제 링크](https://www.acmicpc.net/problem/1269)

### 분류
- 자료 구조
- 정렬

### 문제 요약
- 공집합이 아닌 집합 A와 B의 원소의 개수가 빈 칸을 사이에 두고 입력
- 둘째 줄에는 집합 A의 모든 원소가, 셋째 줄에는 집합 B의 모든 원소가 빈 칸을 사이에 두고 입력
- 각 집합의 원소의 개수는 200,000을 넘지 않으며, 모든 원소의 값은 100,000,000을 넘지 않음
- (A-B)와 (B-A)의 합집합이 A와 B의 대칭 차집합일 때
- 대칭 차집합의 원소의 개수를 출력

### 풀이 아이디어
- HashSet(중복 허용 안 함) 이용
- A와 B를 set에 함께 넣고 각각 A, B를 빼면 각각의 차집합 개수 나옴

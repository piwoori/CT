# [silver 4] 괄호 - 9012

[문제 링크](https://www.acmicpc.net/problem/9012)

### 분류
- 스택

### 문제 요약
- 테스트 데이터 수 정수 T 입력
- 두 개의 괄호 기호인 ‘(’ 와 ‘)’ 만으로 구성되어 있는 괄호 문자열 한 줄씩 입력(하나의 괄호 문자열의 길이는 2 이상 50 이하)
- 한 쌍의 괄호 기호로 된 “( )” 문자열은 기본 VPS 이라할 때
- 입력 괄호 문자열이 올바른 괄호 문자열(VPS)이면 “YES”, 아니면 “NO”를 한 줄에 하나씩 출력

### 풀이 아이디어
- Stack 이용
- pop() push() 이용
- '(' 일 때와 아닐 때를 나눠 진행
- ')' 일 때, 스택이 비었을 때는 계속 진행, 비어져있지 않을 때는 pop() 진행

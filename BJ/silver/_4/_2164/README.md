# [silver 4] 카드2 - 2164

[문제 링크](https://www.acmicpc.net/problem/2164)

### 분류
- 큐

### 문제 요약
- 정수 N(1 ≤ N ≤ 500,000) 입력
- 1부터 N까지 번호가 적힌 카드가 차례대로 놓여있음
- 맨 위의 카드를 버린다. 그 다음 맨 위의 카드를 맨 아래로 옮긴다.
- 위의 과정을 한 장이 남을 때까지 반복
- 마지막에 남는 카드 번호 출력

### 풀이 아이디어
- Queue 자료구조 이용
- poll()로 맨 앞 카드 제거
- 다시 poll()한 값을 offer()로 큐의 뒤에 추가

# [silver 4] 하키 - 1358

[문제 링크](https://www.acmicpc.net/problem/1358)

### 분류
- 기하학

### 문제 요약
- 선수의 수 P, 100보다 작거나 같은 자연수 W와 짝수 H, 절댓값이 100보다 작거나 같은 정수 X와 Y 입력
- 둘째 줄부터 P개의 줄에 절대값이 300보다 작거나 같은 각 선수들의 좌표 x, y 입력
- 하키 링크는 (X, Y)가 가장 왼쪽 아래 모서리인 W * H 크기의 직사각형과, 
반지름이 H/2이면서 중심이 (X, Y+R), (X+W, Y+R)에 있는 두 개의 원으로 이루어져 있음
- 링크 안에 있는 선수의 수를 출력

### 풀이 아이디어
- 경기장을 3개의 영역으로 분리해서 판정
- 중앙 직사각형 영역: X <= x <= X+W 이고 Y <= y <= Y+H
- 왼쪽 반원 영역: 반원의 중심(X, Y + H/2), 반지름(R = H/2), 
x < X 인 경우에만 원 내부 판정 수행, 거리 제곱 비교로 포함 여부 확인 (x - X)^2 + (y - (Y+R))^2 <= R^2
- 오른쪽 반원 영역: 반원의 중심(X+W, Y + H/2), 반지름(R = H/2),
x > X+W 인 경우에만 원 내부 판정 수행, 거리 제곱 비교로 포함 여부 확인 (x - (X+W))^2 + (y - (Y+R))^2 <= R^2
- 세 조건 중 하나라도 만족하면 경기장 안으로 카운트

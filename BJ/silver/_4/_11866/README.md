# [silver 4] 요세푸스 문제0 - 11866

[문제 링크](https://www.acmicpc.net/problem/11866)

### 분류
- 큐

### 문제 요약
- 양의 정수의 앉아 있는 사람의 수 N, 제거할 K번째 입력
- 한 사람이 제거되면 남은 사람들로 이루어진 원을 따라 N명의 사람이 모두 제거될 때까지 이 과정 반복
- 원에서 사람들이 제거되는 순서인 (N, K)-요세푸스 순열을 <n, m, ..., k> 형식으로 출력

### 풀이 아이디어
- Queue 이용
- add() 이용해 원소 입력
- k번째 전까지 poll()한 뒤 offer()로 뒤로 넘김
- k번째 되면 해당 원소 출력

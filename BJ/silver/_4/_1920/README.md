# [silver 4] 수 찾기 - 1920

[문제 링크](https://www.acmicpc.net/problem/1920)

### 분류
- 조건문
- 반복문
- 이진탐색

### 문제 요약
- 자연수 N (1 ≤ N ≤ 100,000)
- N개의 정수 입력 ( -2 ^ 31 이상 2^31 이하)
- M개의 수 입력
- M개의 정수 입력 ( -2 ^ 31 이상 2^31 이하)
- 이 수들이 A안에 존재하면 1 출력, 없으면 0 출력

### 풀이 아이디어
- Arrays.binarySearch(배열, 찾고자하는 수) 함수 이용
- 있으면 찾고자하는 수의 인덱스 반환, 없으면 -1 반환
- 그 전에 배열 오름차순 정렬 필수

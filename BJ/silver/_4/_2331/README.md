# [silver 4] 반복수열 - 2331

[문제 링크](https://www.acmicpc.net/problem/2331)

### 분류
- 조건문
- 반복문

### 문제 요약
- A(1 ≤ A ≤ 9999), P(1 ≤ P ≤ 5) 입력
- D[1] = A, D[n] = D[n-1]의 각 자리의 숫자를 P번 곱한 수들의 합이라고 할 때
- 반복되는 부분을 제외했을 때, 수열에 남게 되는 수들의 개수 출력

### 풀이 아이디어
- list.get(list.size()-1)으로 마지막으로 들어온 요소 얻기
- 숫자 % 10 반복 실행하면서 (int) Math.pow(temp % 10, (double) P)로 제곱 계산
- .contains()로 포함 되어있는지 확인
- .indexOf()으로 인덱스 번호 얻기

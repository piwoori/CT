# [silver 3] 체스판 다시 칠하기 - 1018

[문제 링크](https://www.acmicpc.net/problem/1018)

### 분류
- 이차원 베열

### 문제 요약
- M×N 크기의 보드인 8보다 크거나 같고, 50보다 작거나 같은 자연수 N M 입력
- 어떤 정사각형은 검은색으로 칠해져 있고, 나머지는 흰색으로 칠해져 있음
- 이 보드를 잘라서 8×8 크기의 체스판으로 만듦
- 체스판은 검은색과 흰색이 번갈아서 칠해져 있어야 함
- 보드가 체스판처럼 칠해져 있다는 보장이 없어 8×8 크기의 체스판으로 잘라낸 후에 몇 개의 정사각형을 다시 칠하기로 함
- 다시 칠해야 하는 정사각형의 최소 개수 출력

### 풀이 아이디어
- 문자로 이루어진 N x M 크기의 이차원 배열 list 초기화 
- 반복문과 charAt() 이용해 배열에 한 글자씩 대입
- 변수 min을 64로 초기화
- (0, 0)부터 (N-8, M-8)까지 모든 8×8 시작점을 탐색
- W로 시작하는 경우의 수정 횟수와 B로 시작하는 경우의 수정 횟수를 각각 셈
- 두 경우 중 더 작은 값을 선택
- 모든 8×8 영역에 대해 최솟값을 갱신 후 최종 최솟값을 출력

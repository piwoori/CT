# [silver 3] 프린터 큐 - 1966

[문제 링크](https://www.acmicpc.net/problem/1966)

### 분류
- 큐

### 문제 요약
- 테스트 케이스 개수 T 입력
- 각 테스트 케이스마다 문서 개수 N(1 ≤ N ≤ 100)과 궁금한 문서의 위치 M(0 ≤ M < N) 입력
- N개의 문서는 각각 중요도(우선순위)를 가지며, 큐의 맨 앞 문서를 확인해 아래 규칙을 반복
  - 현재 문서보다 더 높은 중요도의 문서가 큐에 있으면 → 현재 문서를 큐의 뒤로 이동 
  - 그렇지 않으면 → 현재 문서를 출력
- M번째(처음 위치 기준) 문서가 몇 번째로 출력되는지 출력

### 풀이 아이디어
- 큐에 문서의 (초기 인덱스, 중요도) 를 함께 저장
- 매 반복마다 맨 앞 문서를 poll() 한 뒤
  - 큐를 순회하며 현재 문서보다 큰 중요도가 존재하는지 확인 
  - 더 큰 중요도가 있으면 → offer()로 다시 뒤에 넣기 (출력 X)
  - 없으면 → 출력 처리로 카운트 증가, 그리고 이 문서가 M이면 종료
- 출력 순서를 세는 count는 출력될 때만 증가해야 함 (뒤로 보내는 건 카운트 X)

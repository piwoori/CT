# [bronze 4] 삼각형 외우기 - 10101

[문제 링크](https://www.acmicpc.net/problem/10101)

### 분류
- 조건문

### 문제 요약
- 총 3개의 줄에 걸쳐 삼각형의 각의 크기 입력( 0보다 크고, 180보다 작음)
- 세 각의 크기가 모두 60이면, Equilateral 
- 세 각의 합이 180이고, 두 각이 같은 경우에는 Isosceles 
- 세 각의 합이 180이고, 같은 각이 없는 경우에는 Scalene 
- 세 각의 합이 180이 아닌 경우에는 Error
- Equilateral, Isosceles, Scalene, Error 중 하나 출력

### 풀이 아이디어
- 처음엔 세 각의 합 180일 때와 아닐 때의 조건문 실행
- 그 안에서는 모든 각이 60일 때, 셋 중 두 개의 각이 같을 때, 그 외의 조건문 실행

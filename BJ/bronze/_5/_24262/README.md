# [bronze 5] 알고리즘 수업 - 알고리즘의 수행 시간 1 - 24262

[문제 링크](https://www.acmicpc.net/problem/24262)

### 분류
- 시간 복잡도

### 문제 요약
- 입력의 크기 n(1 ≤ n ≤ 500,000) 입력
- MenOfPassion 알고리즘이 다음과 같음
  MenOfPassion(A[], n) {
      i = ⌊n / 2⌋;
      return A[i]; # 코드1
  }
- 첫째 줄에 코드1 의 수행 횟수 출력
- 둘째 줄에 코드1의 수행 횟수를 다항식으로 나타내었을 때, 최고차항의 차수 출력
- 단, 다항식으로 나타낼 수 없거나 최고차항의 차수가 3보다 크면 4를 출력

### 풀이 아이디어
- MenOfPassion은 N을 2로 나눠서 그 수에 해당하는 인덱스의 배열을 출력하는 함수
- 한 번만 실행하게 됨
- 반복도 없고 N이 늘어남에 따라 같이 늘어는 것도 없음으로 시간 복잡도는 상수 2가 됨
- 상수이므로 최고차항의 차수는 0이 됨
- 그러므로 그냥 각 줄에 1 과 0 출력

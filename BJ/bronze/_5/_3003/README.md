# [bronze 5] 킹, 퀸, 룩, 비숍, 나이트, 폰 - 3003

[문제 링크](https://www.acmicpc.net/problem/3003)

### 분류
- 입출력

### 문제 요약
- 동혁이가 찾은 흰색 킹, 퀸, 룩, 비숍, 나이트, 폰의 개수 입력(0보다 크거나 같고 10보다 작거나 같은 정수)
- 체스는 총 16개의 피스를 사용
- 킹 1개, 퀸 1개, 룩 2개, 비숍 2개, 나이트 2개, 폰 8개로 구성
- 입력에서 주어진 순서대로 몇 개의 피스를 더하거나 빼야 되는지를 출력
- 양수라면 동혁이는 그 개수 만큼 피스를 더해야 하는 것이고, 음수라면 제거해야 함

### 풀이 아이디어
- BufferedReader, StringTokenizer 이용
- StringBuilder 이용

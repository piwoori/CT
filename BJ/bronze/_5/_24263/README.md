# [bronze 5] 알고리즘 수업 - 알고리즘의 수행 시간 2 - 24263

[문제 링크](https://www.acmicpc.net/problem/24263)

### 분류
- 시간 복잡도

### 문제 요약
- 입력의 크기 n(1 ≤ n ≤ 500,000) 입력
- MenOfPassion 알고리즘이 다음과 같음
  MenOfPassion(A[], n) {
      sum <- 0;
      for i <- 1 to n
      sum <- sum + A[i]; # 코드1
      return sum;
  }
- 첫째 줄에 코드1 의 수행 횟수 출력
- 둘째 줄에 코드1의 수행 횟수를 다항식으로 나타내었을 때, 최고차항의 차수 출력
- 단, 다항식으로 나타낼 수 없거나 최고차항의 차수가 3보다 크면 4를 출력

### 풀이 아이디어
- MenOfPassion은 1부터 n까지 도는 i를 합한 sum을 리턴하는 함수
- 반복문으로 1부터 n까지 1씩 증가하므로 n번 실행하게 됨
- 시간복잡도는 O(n)이므로 최고차항의 차수는 1이 됨
- 그러므로 그냥 각 줄에 n 과 0 출력

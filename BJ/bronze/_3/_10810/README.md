# [bronze 3] 공 넣기 - 10810

[문제 링크](https://www.acmicpc.net/problem/10810)

### 분류
- 배열

### 문제 요약
- 바구니의 개수 N (1 ≤ N ≤ 100)과 공 넣는 횟수 M (1 ≤ M ≤ 100) 입력
- 둘째 줄부터 M개의 줄에 걸쳐서 공을 넣는 방법 입력
- i번 바구니부터 j번 바구니까지에 k번 번호가 적혀져 있는 공을 넣는다는 의미의 i j k 입력(1 ≤ i ≤ j ≤ N, 1 ≤ k ≤ N)
- 바구니에 공이 이미 있는 경우에는 들어있는 공을 빼고, 새로 공을 넣음
- M번 공을 넣은 이후에 각 바구니에 어떤 공이 들어 있는지 공의 번호 공백으로 구분해 출력

### 풀이 아이디어
- 반복문 이용
- 배열 이용

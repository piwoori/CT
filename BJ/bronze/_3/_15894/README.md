# [bronze 3] 수학은 체육과목 입니다 - 15894

[문제 링크](https://www.acmicpc.net/problem/15894)

### 분류
- 연

### 문제 산약
- 가장 아랫부분의 정사각형 개수 n 입력(1 ≤ n ≤ 10^9)
- 한 변의 길이가 1인 정사각형을 겹치지 않게 빈틈없이 계속 붙여 나감
- 가장 아랫부분의 정사각형이 n개가 되었을 때, 실선으로 이루어진 도형의 둘레의 길이 출력

### 풀이 아이디어
- 4, 8, 12, ... 순으로 증가
- N * 4로 출력
- int의 최대는 21억
- 10^9 = 10억
- 따라서 long 타입으로 변수 설정

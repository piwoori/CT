# [bronze 3] 행렬 덧셈 - 2738

[문제 링크](https://www.acmicpc.net/problem/2738)

### 분류
- 2차원 배열

### 문제 요약
- 행렬의 크기 N 과 M 입력
- 첫 번째 행렬의 N개의 줄에 행렬 A의 원소 M개 차례대로 입력
- 두 번째 행렬의 N개의 줄에 행렬 B의 원소 M개 차례대로 입력
- N과 M은 100보다 작거나 같고, 행렬의 원소는 절댓값이 100보다 작거나 같은 정수
- N개의 줄에 행렬 A와 B를 더한 행렬을 출력
- 행렬의 각 원소는 공백으로 구분

### 풀이 아이디어
- 2차원 배열 이용
- 반복문 이용
- BufferedReader와 StringTokenizer로 빠른 입력
- StringBuilder로 빠른 출력

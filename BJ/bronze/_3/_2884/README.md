# [bronze 3] 알람 시계 - 2884

[문제 링크](https://www.acmicpc.net/problem/2884)

### 분류
- 조건문
- 반복문

### 문제 요약
- 상근이가 설정한 알람 시간 H시 M분을 의미하는 두 정수 H와 M 입력 (0 ≤ H ≤ 23, 0 ≤ M ≤ 59)
- 입력 시간은 24시간 표현을 사용
- 24시간 표현에서 하루의 시작은 0:0(자정)이고, 끝은 23:59(다음날 자정 1분 전)
- 불필요한 0은 사용하지 않음
- 지각하지 않는 창영이의 방법: 45분 앞서는 시간 바꾸기
- 상근이가 창영이의 방법을 사용할 때, 설정해야 하는 알람 시간 출력

### 풀이 아이디어
- 분으로 환산한 total에서 45 빼기
- 음수일 때는 24 * 60 더하기
- 최종 total에서 /, % 이용해 시간 구하기

# [bronze 3] 직사각형에서 탈충 - 1085

[문제 링크](https://www.acmicpc.net/problem/1085)

### 분류
- 조건문
- 반복문

### 문제 요약
- 한수 x, y와 직사각형의 오른쪽 위 꼭짓점 w, h 입력
- 1 ≤ w, h ≤ 1,000과 1 ≤ x ≤ w-1과 1 ≤ y ≤ h-1를 만족하는 정수임
- 직사각형은 각 변이 좌표축에 평행하고, 왼쪽 아래 꼭짓점은 (0, 0)임
- 직사각형의 경계선까지 가는 거리의 최솟값 출력

### 풀이 아이디어
- h - y < d, w - x < d, x < d, y < d 4개의 조건 비교

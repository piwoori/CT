# [bronze 3] 알고리즘 수업 - 알고리즘의 수행 시간 3 - 24264

[문제 링크](https://www.acmicpc.net/problem/24264)

### 분류
- 시간 복잡도

### 문제 요약
- 입력의 크기 n(1 ≤ n ≤ 500,000) 입력
- MenOfPassion 알고리즘이 다음과 같음
  MenOfPassion(A[], n) {
      sum <- 0;
      for i <- 1 to n
          for j <- 1 to n
              sum <- sum + A[i] × A[j]; # 코드1
      return sum;
  }
- 첫째 줄에 코드1 의 수행 횟수 출력
- 둘째 줄에 코드1의 수행 횟수를 다항식으로 나타내었을 때, 최고차항의 차수 출력
- 단, 다항식으로 나타낼 수 없거나 최고차항의 차수가 3보다 크면 4를 출력

### 풀이 아이디어
- MenOfPassion은 1부터 n까지 도는 i와 j의 반복문에서 sum에 A[i] × A[j] 더하기 실행
- 반복문이 1부터 n까지 2번 돌게 되므로 n * n번 실행
- 시간복잡도는 O(n^2)이므로 최고차항의 차수는 2이 됨
- 그러므로 그냥 각 줄에 n * n 과 0 출력
- (1 ≤ n ≤ 500,000)이므로 int의 범위를 벗어나므로 (long) 형변환

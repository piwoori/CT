# [bronze 3] 대지 - 9063

[문제 링크](https://www.acmicpc.net/problem/9063)

### 분류
- 좌표

### 문제 요약
- 임씨가 전쟁 전 자신의 토지 속에 숨겨둔 옥수슬 점의 개수 N (1 ≤ N ≤ 100,000) 입력
- N 줄에는 각 점의 좌표가 두 개의 정수로 한 줄에 하나씩 입력(-10,000 이상 10,000 이하)
- N 개의 점을 둘러싸는 최소 크기의 직사각형의 넓이 출력

### 풀이 아이디어
- max_x, max_y를 각 좌표의 최솟값이 -10000으로 설정
- min_x, min_y를 각 좌표의 최댓값인 10000으로 설정
- 각 좌표가 최댓값보다 크거나, 최솟값보다 작으면 해당 좌표값으로 재설정
- 넓이를 (max_x - min_x) * (max_y - min_y)으로 출력

# [bronze 3] 중앙 이동 알고리즘 - 2903

[문제 링크](https://www.acmicpc.net/problem/2903)

### 분류
- 연산

### 문제 요약
- 알고리즘을 시작하면서 상근이는 정사각형을 이루는 점 4개를 그림
- 정사각형의 각 변의 중앙에 점을 하나 추가 + 정사각형의 중심에 점을 하나 추가를 1번의 과정을 거친다고 함
- 메모리 소모량을 줄이기 위해서 중복하는 점을 한 번만 저장
- 과정을 몇 번 거칠지에 대한 정수 N 입력(1 ≤ N ≤ 15)
- 과정을 N번 거친 후 점의 수를 출력

### 풀이 아이디어
- (2 ^ n + 1) ^ 2으로 나타냄

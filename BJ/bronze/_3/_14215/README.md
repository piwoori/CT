# [bronze 3] 세 막대 - 14215

[문제 링크](https://www.acmicpc.net/problem/14215)

### 분류
- 삼각형

### 문제 산약
- 삼각형을 이루는 세 막대의 길이 a, b, c 입력(1 ≤ a, b, c ≤ 100)
- 각 막대의 길이는 양의 정수
- 세 막대를 이용해서 넓이가 양수인 삼각형을 만들 수 있어야 함
- 삼각형의 둘레를 최대로 해야 함
- 만들 수 있는 가장 큰 삼각형의 둘레 출력

### 풀이 아이디어
- 3 크기의 배열 list에 세 막대의 길이 입력
- Arrays.sort()로 오름차순 정렬
- list[0] + list[1] > list[2]이면 바로 세 길이의 합 출력
- 아니면 나머지 두 길이의 두 배한 값의 1 감소한 2 * (list[0] + list[1]) - 1) 츨력

# [bronze 3] 오븐 시계 - 2525

[문제 링크](https://www.acmicpc.net/problem/2525)

### 분류
- 조건문
- 반복문

### 문제 요약
- 현재 시간 A시 B분을 의미하는 두 정수 A와 B 입력 (0 ≤ H ≤ 23, 0 ≤ M ≤ 59)
- 요리하는 데 필요한 시간 입력(0 ≤ C ≤ 1,000)
- 입력 시간은 24시간 표현을 사용
- 24시간 표현에서 하루의 시작은 0:0(자정)이고, 끝은 23:59(다음날 자정 1분 전)
- 불필요한 0은 사용하지 않음
- 훈제오리구이 요리가 끝나는 시각 출력

### 풀이 아이디어
- 분으로 환산한 total에서 걸리는 시간 더하기
- 총 1440분이 넘어갈 때는 24 * 60 뻬기
- 최종 total에서 /, % 이용해 시간 구하기

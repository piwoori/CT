# [bronze 1] 진법 변환 2 - 11005

[문제 링크](https://www.acmicpc.net/problem/11005)

### 분류
- 진법 변환

### 문제 요약
- 10진법 수인 N과 B진법의 B를 순서으로 입력(2 <= B <= 36)
- 10진법 수 N을 B진법으로 구해 출력

### 풀이 아이디어
- N이 0 초과일 때 진행 되는 반복문 구성
- N % B인 k 변수 설정
- N /= B으로 N 재설정
- k >= 10일 때는 (char) (k + 55)로 변환
- 마지막으로 reverse() 이용해 역순으로 출력

# [bronze 1] 세로읽기 - 10798

[문제 링크](https://www.acmicpc.net/problem/10798)

### 분류
- 2차원 배열

### 문제 요약
- 다섯줄의 문자열 입력
- 각 줄에는 최소 1개, 최대 15개의 글자들이 빈칸 없이 연속으로 주어짐
- 주어지는 글자는 영어 대문자 ‘A’부터 ‘Z’, 영어 소문자 ‘a’부터 ‘z’, 숫자 ‘0’부터 ‘9’ 중 하나
- 다섯 개의 단어를 세로로 읽은 글자들을 공백 없이 출력

### 풀이 아이디어
- [5][15] 크기의이차원 배열 이용
- 글자가 15개 이하이면 나머지는 0으로 채움
- 글자면 출력 0이면 컨티뉴

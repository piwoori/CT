# [bronze 1] 소인수분해 - 11653

[문제 링크](https://www.acmicpc.net/problem/11653)

### 분류
- 소인수분해
- 반복문

### 문제 요약
- 정수 N (1 ≤ N ≤ 10,000,000) 입력
- N의 소인수분해 결과를 한 줄에 하나씩 오름차순으로 출력
- N이 1인 경우 아무것도 출력하지 않음

### 풀이 아이디어
- (int i = 2; i * i <= N; i++) 조건식의 for문 실행
- (N % i == 0) 조건식의 while문 실행
- i 출력 후 N을 i로 나눈 값으로 재설정
- 마지막에 N이  1 이상일 때는 N 출력

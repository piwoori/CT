# [bronze 1] 단어 공부 - 1157

[문제 링크](https://www.acmicpc.net/problem/1157)

### 분류
- 조건문
- 반복문
- 배열
- 아스키코드

### 문제 요약
- 알파벳 대소문자로 된 단어 입력 (길이  1,000,000 미만)
- 대소문자 구분 없이 가장 많이 사용된 알파벳 대문자로 출력

### 풀이 아이디어
- 단어 입력 시 모두 대문자로 바꾸는 .toUpperCase() 이용
- 중복을 걸러야하기 때문에 비교 하려는 변수의 초기값을 비교 대상이 아닌 별도의 -1로 지정
- 형변환 시 (변수 종류) 이용

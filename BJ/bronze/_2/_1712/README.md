# [bronze 2] 손익분기점 - 1712

[문제 링크](https://www.acmicpc.net/problem/1712)

### 분류
- 조건문
- 반복문
- 연산

### 문제 요약
- 21억 이하의 자연수의 고정비용 A, 가변비용 B, 노트북 가격 C 입력
- 손익분기점(최초로 총 수입이 총 비용보다 많아져 이익이 발생하는 지점) 출력
- 손익분기점이 존재하지 않을 때는 -1 출력

### 풀이 아이디어
- 조건문 이용
- 21억 이하의 수는 int, 그 이상은 long 변수 이용
- 나눗셈 시 분모가 0이 될 때 고려

# [bronze 2] 카드게임 - 10801

[문제 링크](https://www.acmicpc.net/problem/10801)

### 분류
- 반복문
- 조건문

### 문제 요약
- A와 B는 1부터 10까지의 숫자가 하나씩 적힌 열 장의 카드로 게임 진행
- 각 라운드는 더 높은 숫자를 제시한 사람이 승리하고, 제시한 숫자가 같은 경우는 비김
- 열 번의 라운드에서 더 많은 라운드를 승리한 사람이 게임을 승리하고, 승리한 라운드 횟수가 동일한 경우 비김
- 첫 번째 줄에는 A가 제시한 카드의 숫자 10개가 라운드 순서대로 주어지고, 두 번째 줄에는 B가 제시한 카드의 숫자 10개가 라운드 순서대로 입력
- 게임의 승패가 결정되는 경우 승리한 사람을 출력, 비기는 경우에는 D를 출력

### 풀이 아이디어
- 배열 이용
- for문, if문 이용

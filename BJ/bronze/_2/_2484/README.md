# [bronze 2] 주사위 네개 - 2484

[문제 링크](https://www.acmicpc.net/problem/2484)

### 분류
- 조건문
- 반복문
- 배열
- 리스트

### 문제 요약
- 참여하는 사람 수 N 입력
- N개의 줄에 사람들이 주사위를 던진 4개의 눈이 빈칸을 사이에 두고 입력
- 같은 눈이 4개가 나오면 50,000원+(같은 눈)×5,000원의 상금
- 같은 눈이 3개만 나오면 10,000원+(3개가 나온 눈)×1,000원의 상금
- 같은 눈이 2개씩 두 쌍이 나오는 경우에는 2,000원+(2개가 나온 눈)×500원+(또 다른 2개가 나온 눈)×500원의 상금
- 같은 눈이 2개만 나오는 경우에는 1,000원+(같은 눈)×100원의 상금
- 모두 다른 눈이 나오는 경우에는 (그 중 가장 큰 눈)×100원의 상금
- 가장 많은 상금을 받은 사람의 상금 출력

### 풀이 아이디어
- for 문 이용
- 배열 두 개 이용
- 리스트로 같은 눈 2개일 때 이용

# [bronze 2] 바구니 뒤집기 - 10811

[문제 링크](https://www.acmicpc.net/problem/10811)

### 분류
- 반복문
- 조건문

### 문제 요약
- 바구니의 개수 N, 바구니 번호의 순서를 역순으로 바꿀 횟수 M 입력(1 ≤ N, M ≤ 100)
- 각 바구니에는 왼쪽부터 1번부터 N번까지 번호가 매겨져 있읔
- M개의 줄에 번호의 순서를 역순으로 바꿀 범위를 나타내는 정수 i, j 입력(1 ≤ i ≤ j ≤ N)
- M번 바구니의 순서를 역순으로 만든 다음
- 바구니에 적혀있는 번호를 가장 왼쪽 바구니부터 공백으로 구분해 출력

### 풀이 아이디어
- 배열 이용
- 반복문 while(x < y) 이용

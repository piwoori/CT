# [bronze 2] 다이얼 - 5622

[문제 링크](https://www.acmicpc.net/problem/5622)

### 분류
- 반복문
- 조건문
- 문자열

### 문제 요약
- 알파벳 대문자로 이루어진 단어 입력(2 이상 15 이하)
- 한 알파벳에 헤당하는 번호를 누른 다음에 금속 핀이 있는 곳까지 시계방향으로 돌림
- 숫자를 하나 누르면 다이얼이 처음 위치로 돌아가고, 다음 숫자를 누르려면 다이얼을 처음 위치에서 다시 돌려야 함
- 숫자 1을 걸려면 총 2초가 필요
- 1보다 큰 수를 거는데 걸리는 시간은 이보다 더 걸리며, 한 칸 옆에 있는 숫자를 걸기 위해선 1초씩 더 걸림
- 다이얼을 걸기 위해서 필요한 최소 시간 출력

### 풀이 아이디어
- 조건문 이용
- 'A' <= value && value <= 'C' 과 같은 조건식 이용

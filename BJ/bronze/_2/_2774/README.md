# [bronze 2] 아름다운 수 - 2774

[문제 링크](https://www.acmicpc.net/problem/2774)

### 분류
- 반복문
- 조건문
- 배열

### 문제 요약
- 테스트 케이스 개수 T 입력
- 알고 싶은 수 입력
- 10진수의 서로 다른 숫자의 개수 출력

### 풀이 아이디어
- charAt() 이용해 배열 저장
- 제네릭 <> 이용
- set, for (int n : 배열) set.add(n) 이용
- Collections.sort() 이용
- cf) 배열은 Arrays.sort()
- size() 이용
- cf) 배열은 length, 문자열은 length()

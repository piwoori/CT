# [bronze 2] 공 바꾸기 - 10813

[문제 링크](https://www.acmicpc.net/problem/10813)

### 분류
- 반복문
- 조건문

### 문제 요약
- 바구니의 개수 N, 공을 교환할 횟수 M 입력(1 ≤ N, M ≤ 100)
- 1번부터 N번까지 번호가 매겨져 있는 바구니에는 바구니에 적혀있는 번호와 같은 번호가 적힌 공이 들어있음
- M개의 줄에 걸쳐서 공을 교환할 방법을 나타내는 정수 i, j 입력(1 ≤ i ≤ j ≤ N)
- i번 바구니와 j번 바구니에 들어있는 공을 교환
- 1번 바구니부터 N번 바구니에 들어있는 공의 번호를 공백으로 구분해 출력

### 풀이 아이디어
- 배열 이용
- 반복문 이용

# [bronze 2] 진법 변환 - 2745

[문제 링크](https://www.acmicpc.net/problem/2745)

### 분류
- 진법 변환

### 문제 요약
- B진번 수인 N을 N과 B 순으로 입력(2 <= B <= 30)
- B진법 수 N을 10진법으로 구해 출력

### 풀이 아이디어
- N을 맨 오른쪽부터 돌아가며 반복문 시작
- 'A' <= ch && ch <= 'Z' 일 때 sum += (C - 'A' + 10) * tmp
- 그 외는 sum += (C - '0') * tmp;
- 한 번 돌고나서는  temp *= 10 해주기

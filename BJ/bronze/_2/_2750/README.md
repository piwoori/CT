# [bronze 2] 수 정렬하기 - 2750

[문제 링크](https://www.acmicpc.net/problem/2750)

### 분류
- 반복문
- 배열

### 문제 요약
- 수의 개수 N(1 ≤ N ≤ 1,000) 입력
- 둘째 줄부터 한 줄씩 중복되지 않는 절댓값이 1,000보다 작거나 같은 수 입력
- 첫째 줄부터 N개의 줄에 오름차순으로 정렬한 결과를 한 줄에 하나씩 출력

### 풀이 아이디어
- BufferedReader 이용해 입력 받기
- N 크기의 배열 초기화
- 반복문으로 하나씩 저장
- Arrays.sort() 이용해 오름차순 정렬
- StringBuilder 초기화해 빠른 출력
- 반복문으로 StringBuilder에 하나씩 쌓기
- 마지막으로 한꺼번에 출력

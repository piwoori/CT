# [bronze 2] 문자열 반복 - 2675

[문제 링크](https://www.acmicpc.net/problem/2675)

### 분류
- 반복문
- 조건문
- 문자열

### 문제 요약
- 테스트 케이스의 개수 T(1 ≤ T ≤ 1,000) 입력
- 반복 횟수 R(1 ≤ R ≤ 8), 문자열 S가 공백으로 구분되어 입력
- 첫 번째 문자를 R번 반복하고, 두 번째 문자를 R번 반복하는 식으로 만든 P 출력

### 풀이 아이디어
- BufferedReader, StringTokenizer, StringBuilder로 빠른 입출력
- .length() 이용

# [bronze 2] 블랙잭 - 2798

[문제 링크](https://www.acmicpc.net/problem/2798)

### 분류
- 반복문
- 조건문
- 배열

### 문제 요약
- 첫째 줄에 카드의 개수 N(3 ≤ N ≤ 100)과 M(10 ≤ M ≤ 300,000) 입력
- 둘째 줄에는 카드에 쓰여 있는 수 입력(100,000을 넘지 않는 양의 정수)
- 합이 M을 넘지 않는 카드 3장을 찾을 수 있는 경우만 입력됨
- N장의 카드 중에서 3장의 카드를 골라 합이 M을 넘지 않으면서 M과 최대한 가깝게 만들어야 함
- M을 넘지 않으면서 M에 최대한 가까운 카드 3장의 합을 출력

### 풀이 아이디어
- 배열로 입력 받기
- max 변수 설정
- i가 0부터 N - 2까지 도는 반복문, j가 i부터 N -1까지 도는 반복문, j가 N까지 도는 반복문 실행
- sum = list[i] + list[j] + list[k]로 설정
- sum <= M && sum > max 조건식을 만족하면 max에 sum을 대입
- max 출력

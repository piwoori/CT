# [bronze 2] 벌집 - 2292

[문제 링크](https://www.acmicpc.net/problem/2292)

### 분류
- 조건문
- 반복문
- 연산

### 문제 요약
- 벌집 중앙의 방 1부터 시작해서 이웃하는 방에 돌아가면서 1씩 증가하는 번호를 주소로 매길 수 있음
- 구하려는 방의 숫자 N 입력(1 ≤ N ≤ 1,000,000,000)
- 벌집의 중앙 1에서 N번 방까지 최소 개수의 방을 지나서 갈 때 몇 개의 방을 지나가는지 출력

### 풀이 아이디어
- 한 층씩 갈 때마다 6씩 증가
- 현재 층의 최대 값까지 더해감
- N이 포함되면 멈추기
- 증가량 = 6 * (층 번호 - 1)

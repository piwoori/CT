# [bronze 2] 소수 찾기 - 1978

[문제 링크](https://www.acmicpc.net/problem/1978)

### 분류
- 소수

### 문제 요약
- 테스트 케이스 개수 N 입력(100이하)
- N개의 1,000 이하의 자연수 입력
- 소수의 개수를 출력

### 풀이 아이디어
- boolean is_prime = X != 1 로 설정
- (int j = 2; j * j <= X; j++) 조건식을 도는 조건문 실행
- 약수는 항상 쌍으로 존재하기에 해당 수의 제곱근 까지만 반복문 돌아도 됨
- 하나라도 X % j == 0 를 만족하면 소수 탈락

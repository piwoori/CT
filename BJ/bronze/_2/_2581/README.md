# [bronze 2] 소수 - 2581

[문제 링크](https://www.acmicpc.net/problem/2581)

### 분류
- 소수

### 문제 요약
- 소수를 찾고 싶은 범위 중 최솟값 자연수 M 입력(M <= N <= 10,000)
- 다음 줄에 최댓값 N 입력(M <= N <= 10,000)
- 수인 것을 모두 찾아 첫째 줄에 그 합을, 둘째 줄에 그 중 최솟값 출력
- 소수가 없을 경우는 첫째 줄에 -1 출력

### 풀이 아이디어
- i가 M에서부터 N까지 도는 반복문 실행
- boolean is_prime = i != 1로 변수 설정
- (int j = 2; j * j <= i; j++) 조건식의 반복문 실행
- i % j == 0을 만족하면 is_prime = false 설정 후 break
- j 다 돈 후 is_prime true 면 sum에 추가, min 최소면 갱신
- sum > 0 이면 합, 최솟값 츨력
- sum = 0 이면 -1 출력

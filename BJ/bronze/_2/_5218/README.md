# [bronze 2] 알파벳 거리 - 5218

[문제 링크](https://www.acmicpc.net/problem/5218)

### 분류
- 반복문
- 조건문
- 아스키코드

### 문제 요약
- 테스트 케이스 수 T 입력
- 길이가 같은 대문자 단어 x와 y 입력
- 알파벳에 숫자를 할당한 뒤,  y≥ x인 경우에는 y-x, y < x인 경우에는 (y+26) - x가 알파벳 거리가 됨
- 각 테스트 케이스 마다 각 글자의 알파벳 거리를 공백으로 구분해 출력

### 풀이 아이디어
- for 문 이용
- if 문 이용
- 문자로 이루어진 배열의 원소를 - 연산자 이용하면 아스키코드 값으로 활용 가능

# [bronze 2] 초6 수학 - 202

[문제 링크](https://www.acmicpc.net/problem/2702)

### 분류
- 반복문
- 조건문
- 함수

### 문제 요약
- 테스트 케이스 개수 T 입력
- 정수 a, b 공백 구분으로 입력
- 최소공배수, 최대공약수 출력

### 풀이 아이디어
- Main 밖에서 함수 선언
- 최대공약수: 유클리드 호제법(나머지가 0이 될 때까지 두 수를 계속 나눔) 이용
- 최소공배수: 두 수를 곱한 값을 최대공약수로 나눔
- 함수를 static(객체 없어도 쓸 수 있게 만듦)으로 선언했었으면, 함수 쓰기 전에 초기화? 안 해도 됨

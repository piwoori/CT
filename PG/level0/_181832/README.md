# [level 0] 정수를 나선형으로 배치하기 - 181832

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181832)

### 분류
- 반복문
- 조건문
- 2차원 배열

### 문제 요약
- 정수 n 매개변수
- n × n 크기의 이차원 배열 생성
- 배열의 시작점 (0, 0)부터 시계 방향(오른쪽 → 아래 → 왼쪽 → 위) 으로 이동하며 1부터 n²까지의 숫자를 차례대로 채움
- 모든 칸이 채워진 이차원 배열 반환

### 풀이 아이디어
- n × n 크기의 2차원 배열을 0으로 초기화
- 현재 위치 (x, y)와 현재 채울 숫자 num으로 관리
- 이동 방향을 오른쪽, 아래, 왼쪽, 위 순서로 정의한 뒤 인덱스로 제어
- 배열 범위를 벗어나거나, 이미 값이 채워진 경우 방향을 전환
- num이 n²가 될 때까지 반복하며 배열을 채움

# [level0]
외계행성의 나이 - 120834

[문제 링크](https://www.acmicpc.net/problem/120834)

### 분류
- 딕셔너리

### 문제 요약
- 나이 age 매개변수
- PROGRAMMERS-962 행성에서는 나이를 알파벳으로 말함
- a는 0, b는 1, c는 2, ..., j는 9로 표현
- PROGRAMMER-962식 나이 리턴

### 풀이 아이디어
- 딕셔너리 {}로 '숫자': '알파벳' 으로 저장
- "".join() 이용
- for i in str(age)으로 나이를 문자열로 변환
- 딕셔너리[i]로 키에 해당하는 값 반환

# [level0] 정사각형으로 만들기 - 181830

[문제 링크](https://www.acmicpc.net/problem/181830)

### 분류
- 조건문
- 반복문
- 2차원 배열

### 문제 요약
- 2차원 배열 arr 매개변수
- arr의 행의 수가 더 많다면 열의 수가 행의 수와 같아지도록 각 행의 끝에 0을 추가
- 열의 수가 더 많다면 행의 수가 열의 수와 같아지도록 각 열의 끝에 0을 추가
- 최종 이차원 배열 리턴

### 풀이 아이디어
- 행 > 열일 때: 각 행에 (row - col)개의 0을 뒤에 추가하여 열 개수 맞추기
- 행 < 열일 때: [0] * col 형태의 행을 (col - row)번 추가하여 행 개수를 맞추기
- 행 == 열일 때: 그대로 반환

# [level0] 안전지대 - 120866

[문제 링크](https://www.acmicpc.net/problem/120866)

### 분류
- 배열
- 반복문

### 문제 요약
- 지뢰가 매설된 지역의 지도 board 매개변수
- 지뢰는 2차원 배열 board에 1로 표시되어 있고 board에는 지뢰가 매설 된 지역 1과, 지뢰가 없는 지역 0만 존재
- 안전한 지역의 칸 수 리턴

### 풀이 아이디어
- 1일 때 max(0, i - 1), min(n, i + 2) 를 만족하며, 그 요소가 1일 때 -1로 변경
- count()로 0인 개수 확인

# [level 0] 전국 대회 선발 고사 - 181851

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181851)

### 분류
- 리스트

### 문제 요약
- 각 학생들의 선발 고사 등수를 담은 정수 배열 rank와 전국 대회 참여 가능 여부가 담긴 boolean 배열 attendance 매개변수
- 참여가 가능한 학생 중 등수가 높은 3명을 선발
- 전국 대회에 선발된 학생 번호들을 등수가 높은 순서대로 각각 a, b, c번이라고 할 때 10000 × a + 100 × b + c 리턴

### 풀이 아이디어
- 2차원 배열 이용헤 번호와 등수 저장

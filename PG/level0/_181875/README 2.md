# [level 0] 배열에서 문자열 대소문자 변환하기 - 181875

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181875)

### 분류
- 문자열

### 문제 요약
- 모든 원소가 알파벳으로만 이루어진 문자열 배열 strArr 매개변수
- 배열에서 홀수번째 인덱스의 문자열은 모든 문자를 대문자로, 짝수번째 인덱스의 문자열은 모든 문자를 소문자로 바꿔서 리턴

### 풀이 아이디어
- .lower(), .upper() 이용
- enumerate 이용해 인덱스와 요소 값 이용

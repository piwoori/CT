# [level 0] 무작위로 k개의 수 뽑기 - 181858

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181858)

### 분류
- 리스트

### 문제 요약
- 정수 배열 arr, 완성될 배열의 길이 k 매개변수
- 이미 어떤 수가 무작위로 주어질지 알고 있다고 가정하고, 실제 만들어질 길이 k의 배열을 예상
- 지금까지 나온적이 없는 수이면 배열 맨 뒤에 추가
-  완성될 배열의 길이가 k보다 작으면 나머지 값을 전부 -1로 채워서 리턴

### 풀이 아이디어
- extend(): 파라미터를 각각 하나의 요소로 추가 이용
- 반복문 이용
- 여러 개 추가하고 싶으면 [] * 횟수 이용

# [level0] 모스부호 (1) - 120838

[문제 링크](https://www.acmicpc.net/problem/120838)

### 분류
- 딕셔너리

### 문제 요약
- 문자열 letter 매개변수(공백으로 구분)
- 모스부호는 다음과 같음
- '.-':'a','-...':'b','-.-.':'c','-..':'d','.':'e','..-.':'f',
  '--.':'g','....':'h','..':'i','.---':'j','-.-':'k','.-..':'l',
  '--':'m','-.':'n','---':'o','.--.':'p','--.-':'q','.-.':'r',
  '...':'s','-':'t','..-':'u','...-':'v','.--':'w','-..-':'x',
  '-.--':'y','--..':'z'
- letter를 영어 소문자로 바꾼 문자열 리턴

### 풀이 아이디어
- 고정된 규칙으로 1:1 변환 되기에 딕셔너리 이용
- "".join() 이용해 이어 붙임
- split(" ")으로 문자열 추출

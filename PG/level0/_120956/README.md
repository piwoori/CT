# [level0] 옹알이 (1) - 120956

[문제 링크](https://www.acmicpc.net/problem/120956)

### 분류
- 조건문
- 반복문
- 배열

### 문제 요약
- 문자열 배열 babbling 매개변수
- "aya", "ye", "woo", "ma" 네 가지 발음만 가능
- 발음할 수 있는 단어의 개수 리턴

### 풀이 아이디어
- 발음 할 수 있는 문자열이 원소인 배열 생성
- 이중 방복문 이용
- 해당 발음 부분이 있다면 1로 변경
- isdigit() 이용해 숫자로만 이루어져있는지 판단

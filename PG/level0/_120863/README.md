# [level0] 다항식 더하기 - 120863

[문제 링크](https://www.acmicpc.net/problem/120863)

### 분류
- 배열
- 반복문

### 문제 요약
- 덧셈으로 이루어진 다항식 polynomial 매개변수
- 동류항끼리 더한 결괏값을 문자열 리턴
- 같은 식이라면 가장 짧은 수식 리턴

### 풀이 아이디어
- .split(" + ") 이용해 분리
- 분리된 요소들 중에 x가 있을 때와 없을 때로 구분
- x가 있을 때, 단순히 x만 있을 때는 x_sum 변수에 + 1
- 그 외에는 [:-1]로 계수먼 추출해 x_sum에 더하기
- x_sum나 num_sum이 1이면 answer에 x만 더하기
- 그 외에는 str로 형 변환 후 더하기

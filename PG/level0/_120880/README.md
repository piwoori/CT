# [level0] 특이한 정렬 - 120880

[문제 링크](https://www.acmicpc.net/problem/120880)

### 분류
- 배열

### 문제 요약
- 정수가 담긴 배열 numlist와 정수 n 매개변수
- 정수 n을 기준으로 n과 가까운 수부터 정렬해 n으로부터의 거리가 같다면 더 큰 수를 앞에 오도록 배치
- numlist의 원소를 n으로부터 가까운 순서대로 정렬한 배열 리턴

### 풀이 아이디어
- sorted(데이터, key) 이용
- n과 가까운 순서대로 정렬 후 거리가 같으면 더 큰 수가 먼저 오도록 정렬

# [level 0] 완쪽 오른쪽 - 181890

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181890)

### 분류
- 리스트 슬라이싱

### 문제 요약
- "u", "d", "l", "r" 네 개의 문자열이 여러 개 저장되어 있는 문자열 리스트 str_list 매개변수
- str_list에서 "l"과 "r" 중 먼저 나오는 문자열이 "l"이라면 해당 문자열을 기준으로 왼쪽에 있는 
문자열들을 순서대로 담은 리스트를, 먼저 나오는 문자열이 "r"이라면 해당 문자열을 기준으로 오른쪽에 있는 문자열들을 순서대로 담은 리스트 리턴
-  "l"이나 "r"이 없다면 빈 리스트 리턴

### 풀이 아이디어
- 인덱스 슬라이싱 이용
- return은 반복문 종료도 포함됨

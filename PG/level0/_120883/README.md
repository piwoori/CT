# [level0] 로그인 성공? - 120883

[문제 링크](https://www.acmicpc.net/problem/120883)

### 분류
- 조건문

### 문제 요약
- 머쓱이가 입력한 아이디와 패스워드가 담긴 배열 id_pw와 회원들의 정보가 담긴 2차원 배열 db 매개변수
- 아이디와 비밀번호가 모두 일치하는 회원정보가 있으면 "login" 리턴
- 로그인이 실패했을 때 아이디가 일치하는 회원이 없다면 “fail” 리턴
- 아이디는 일치하지만 비밀번호가 일치하는 회원이 없다면 “wrong pw” 리턴

### 풀이 아이디어
- 반복문 이용
- 조건문 이용

# [level 0] 날짜 비교하기 - 181838

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181838)

### 분류
- 조건문

### 문제 요약
- 각각 날짜를 나타내는 [year, month, day] 꼴로 주어진 정수 배열 date1과 date2 매개변수
- year는 연도를, month는 월을, day는 날짜를 나타냄
- date1이 date2보다 앞서는 날짜라면 1을, 아니면 0 리턴

### 풀이 아이디어
- 부등호로 배열 비교 후 int()로 형변환

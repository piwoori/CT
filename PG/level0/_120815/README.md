# [level0] 피자 나눠 먹기 (2) - 120815

[문제 링크](https://www.acmicpc.net/problem/120815)

### 분류
- 반복문
- 조건문
- 연산

### 문제 요약
- 피자를 나눠먹을 사람의 수 n 매개변수
- 머쓱이네 피자가게는 피자를 여섯 조각으로 잘라 줌
- n명이 주문한 피자를 남기지 않고 모두 같은 수의 피자 조각을 먹어야 한다면 최소 몇 판을 시켜야 하는지 리턴

### 풀이 아이디어
- answer = 1로 초기화
- (6 * answer) % n != 0 조건식의 while문 실행
- answer += 1
- answer 리턴

# [level0] 가까운 수 - 120890

[문제 링크](https://www.acmicpc.net/problem/120890)

### 분류
- 배열

### 문제 요약
- 정수 배열 array와 정수 n 매개변수
- array에 들어있는 정수 중 n과 가장 가까운 수 리턴

### 풀이 아이디어
- min() 함수의 key 옵션을 활용하여 정렬 기준을 직접 설정
- 각 원소 x를 (abs(n - x), x) 형태의 튜플로 변환하여 비교
- 첫 번째 기준: abs(n - x) → n과의 거리 
- 두 번째 기준: x → 거리가 같을 경우 더 작은 값 선택
- 파이썬의 튜플 비교는 앞에서부터 순차적으로 이루어지므로 거리 → 값 순으로 자동 정렬됨

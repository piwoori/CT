# [level0] 치킨 쿠폰 - 120884

[문제 링크](https://www.acmicpc.net/problem/120884)

### 분류
- 몫, 나머지

### 문제 요약
- 시켜먹은 치킨의 수 chicken 매개변수(0 ≤ chicken ≤ 1,000,000)
- 프로그래머스 치킨은 치킨을 시켜먹으면 한 마리당 쿠폰을 한 장 발급
- 폰을 열 장 모으면 치킨을 한 마리 서비스로 받을 수 있음
- 서비스 치킨에도 쿠폰 발급
- 받을 수 있는 최대 서비스 치킨의 수 리턴

### 풀이 아이디어
- while문 이용
- 10으로 나눈 // 몫과 % 나머지 구하기
- 몫은 서비스 받는 치킨 수에 더하기
- 몫과 나머지의 합으로 chicken 변수 초기화

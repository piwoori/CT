# [level 0] 배열의 길이를 2의 거듭제곱으로 만들기 - 181857

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181857)

### 분류
- 리스트

### 문제 요약
- 정수 배열 arr 매개변수
- arr의 길이가 2의 정수 거듭제곱이 되도록 arr 뒤에 정수 0을 최소한으로 추가한 배열 리턴

### 풀이 아이디어
- 2의 거듭제곱을 요소로 하는 배열 생성
- 1 ≤ arr의 길이 ≤ 1,000 이기에 배열 총 11 크기로 설정
- 거듭제곱 배열에 arr의 길이가 없으면 있을 때까지 0 추가
- .append() 이용

# [level1] 수박수박수박수박수박수? - 12922

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12922)

### 분류
- 문자열

### 문제 요약
- 얻고 싶은 문자열의 길이 n 매개변수
  - n은 길이 10,000이하인 자연수입
-  "수박수박수박수...."와 같은 패턴을 유지하는 문자열 리턴

### 풀이 아이디어
- 문자열 변수 s를 ""로 초기회
- 정수 변수 i가 0부터 n - 1까지 도는 for문 실행
  - i % 2 == 0의 조건식 만족하면
    - answer +="수" 실행
  - 아닐 시
    - answer += "박" 실행
- answer 리턴

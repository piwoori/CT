# [level1] 체육복 - 42862

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/42862)

### 분류
- 배열

### 문제 요약
- 전체 학생의 수 n, 체육복을 도난당한 학생들의 번호가 담긴 배열 lost, 여벌의 체육복을 가져온 학생들의 번호가 담긴 배열 reserve 매개변수
  - 전체 학생의 수는 2명 이상 30명 이하
  - 체육복을 도난당한 학생의 수는 1명 이상 n명 이하이고 중복되는 번호는 없음
  - 여벌의 체육복을 가져온 학생의 수는 1명 이상 n명 이하이고 중복되는 번호는 없음
  - 여벌 체육복이 있는 학생만 다른 학생에게 체육복을 빌려줄 수 있음
  - 여벌 체육복을 가져온 학생이 체육복을 도난당했을 수 있음
    - 이  학생은 체육복을 하나만 도난당했다고 가정하며, 남은 체육복이 하나이기에 다른 학생에게는 체육복을 빌려줄 수 없음
- 체육복이 없으면 수업을 들을 수 없기 때문에 체육복을 적절히 빌려 최대한 많은 학생이 체육수업을 들어야 함
- 체육수업을 들을 수 있는 학생의 최댓값 리턴

### 풀이 아이디어
- 작은 번호부터 처리하기 위해 Arrays.sort(lost)과 Arrays.sort(reserve) 실행
- 여벌이 있지만 잃어버린 학생 처리하기 위해 정수 변수 i가 0부터 lost.length 전까지 도는 for문 실행
  - 정수 변수 j가 0부터 reserve.length 전까지 도는 for문 실행
    - lost[i] == reserve[j] 조건식 만족 시
      - lost[i]와 reserve[j]에 -1 대입
      - 처리한 학생을 또 다루지 않기 위해 break 실행
- 체육 수업을 들을 수 있는 학생 수를 나타내는 정수 변수 answer을 n - lost.length로 초기화
- 체육복 빌리기 위해 정수 변수 i가 0부터 lost.length 전까지 도는 for문 실행
  - lost[i] == -1 조건식 만족 시
    - answer++ 실행 후 뒤에 오는 반복문 실행하지 않기 위해 continue 실행
  - 정수 변수 j가 0부터 reserve.length 전까지 도는 for문 실행
    - reserve[j] == lost[i] - 1 || reserve[j] == lost[i] + 1 조건식 만족 시
      - answer++ 실행
      - 여분 체육복이 없기에 reserve[j]에 -1 대입 후 break 실행
- answer 리턴

# [level1] [PCCP 기출문제] 1번 / 붕대 감기 - 250137

### 분류

### 문제 요약
- 붕대 감기 기술의 시전 시간, 1초당 회복량, 추가 회복량을 담은 1차원 정수 배열 bandage와 최대 체력을 의미하는 정수 health, 몬스터의 공격 시간과 피해량을 담은 2차원 정수 배열 attacks 매개변수
  - bandage는 [시전 시간, 초당 회복량, 추가 회복량] 형태의 길이가 3인 정수 배열
    - 1 ≤ 시전 시간 = t ≤ 50
    - 1 ≤ 초당 회복량 = x ≤ 100
    - 1 ≤ 추가 회복량 = y ≤ 100
  - 1 ≤ health ≤ 1,000
  - 1 ≤ attacks의 길이 ≤ 100
    - attacks[i]는 [공격 시간, 피해량] 형태의 길이가 2인 정수 배열
    - attacks는 공격 시간을 기준으로 오름차순 정렬된 상태
    - attacks의 공격 시간은 모두 다름
    - 1 ≤ 공격 시간 ≤ 1,000
    - 1 ≤ 피해량 ≤ 100
- 어떤 게임에는 붕대 감기라는 기술이 있음
- 붕대 감기는 t초 동안 붕대를 감으면서 1초마다 x만큼의 체력을 회복
- t초 연속으로 붕대를 감는 데 성공한다면 y만큼의 체력을 추가로 회복
- 게임 캐릭터에는 최대 체력이 존재해 현재 체력이 최대 체력보다 커지는 것은 불가능
- 기술을 쓰는 도중 몬스터에게 공격을 당하면 기술이 취소되고, 공격을 당하는 순간에는 체력을 회복할 수 없음
- 몬스터에게 공격당해 기술이 취소당하거나 기술이 끝나면 그 즉시 붕대 감기를 다시 사용하며, 연속 성공 시간이 0으로 초기화
- 몬스터의 공격을 받으면 정해진 피해량만큼 현재 체력이 줄어즒
- 현재 체력이 0 이하가 되면 캐릭터가 죽으며 더 이상 체력을 회복할 수 없음
- 모든 공격이 끝난 직후 남은 체력 리턴
  - 만약 몬스터의 공격을 받고 캐릭터의 체력이 0 이하가 되어 죽는다면 -1 리턴

### 풀이 아이디어
- 캐릭터의 최대 체력을 나타내는 정수 변수 maxHealth를 health로 초기화
- 붕대 감기의 시전 시간을 나타내는 정수 변수 t를 bandage[0]로 초기화
- 붕대 감기의 초당 회복력을 나타내는 정수 변수 x를 bandage[1]로 초기화
- 붕대 감기의 추가 회복력을 나타내는 정수 변수 y를 bandage[0]로 초기화
- 연속으로 붕대 감기를 성공한 횟수를 나타내는 정수 변수 success를 0으로 초기롸
- 몇 번째 공격인지를 나타내는 정수 변수 attackIndex를 0으로 초기화
- 가장 긴 공격 시간을 나타내는 정수 변수 lastTime을 attacks[attacks.length - 1][0]으로 초기화
- 정수 변수 time이 1부터 lastTime까지 도는 for문 실행
  - attackIndex < attacks.length && attacks[attackIndex][0] == time 조건식 만족 시
    - health에 attacks[attackIndex][1] 빼기 
    - success를 다시 0으로 초기화
    - health <= 0 조건식 만족 시
      - -1 리턴
    - attackIndex++ 실행
  - 그 외일 때는
    - health에 x 더하기
    - success++ 실행
    - success == t 조건식 만족 시
      - health에 y 더하기
      - success를 0으로 초기화
    - health에 Math.min(health, maxHealth) 대입
- health 리턴

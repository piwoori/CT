# [level1] 가장 가까운 같은 글자 - 142086

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/142086)

### 분류
- 문자열

### 문제 요약
- 문자열 s 매개변수
  - 1 ≤ s의 길이 ≤ 10,000
  - s은 영어 소문자로만 구성
- s의 각 위치마다 자신보다 앞에 나왔으면서, 자신과 가장 가까운 곳에 있는 같은 글자가 어디 있는지 찾으려함
- s="banana"라고 할 때,  각 글자들을 왼쪽부터 오른쪽으로 읽어 나가면서 다음과 같이 진행
  - b는 처음 나왔기 때문에 자신의 앞에 같은 글자가 없음. 이는 -1로 표현 
  - a는 처음 나왔기 때문에 자신의 앞에 같은 글자가 없음. 이는 -1로 표현 
  - n은 처음 나왔기 때문에 자신의 앞에 같은 글자가 없음. 이는 -1로 표현 
  - a는 자신보다 두 칸 앞에 a가 있음 .이는 2로 표현 
  - n도 자신보다 두 칸 앞에 n이 있음 이는 2로 표현 
  - a는 자신보다 두 칸, 네 칸 앞에 a가 있음. 이 중 가까운 것은 두 칸 앞이고, 이는 2로 표현
  - 최종 결과물은 [-1, -1, -1, 2, 2, 2]
- 위와 같이 정의된 연산을 수행하여 최종 배열 리턴

### 풀이 아이디어
- s.length() 크기의 정수 배열 answer 초기화
- Map<Chracter, Integer> map을 HashMap 구현체로 초기화
- 정수 변수 i가 0부터 s.length() 전까지 도는 for문 실행
  - 문자 변수 c를 s.charAt(i)로 초기화
  - map.containsKey(c)의 조건식을 만족 시
    - answer[i]를 i - map.get(c) 대입해 같은 글자의 가장 가까운 위치 저장
  - 아닐 시
    - answer[i]에 -1 대입
  - map.put(c, i) 실행해 글자 자리 갱신
- answer 리턴

# [level1] [PCCE 기출문제] 9번 / 지폐 접기 - 340199

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/340199)

### 분류
- 배열

### 문제 요약
- 지갑의 가로, 세로 크기를 담은 정수 리스트 wallet과 지폐의 가로, 세로 크기를 담은 정수 리스트 bill 매개변수
  - wallet의 길이 = bill의 길이 = 2
  - 10 ≤ wallet[0], wallet[1] ≤ 100
  - 10 ≤ bill[0], bill[1] ≤ 2,000
- 지폐마다 크기가 달라 지갑에 넣으려면 여러 번 접어서 넣어야 함
- 90도 돌려서 지갑에 넣을 수 있음
- 지폐를 접을 때는 다음과 같은 규칙을 지킴
  - 지폐를 접을 때는 항상 길이가 긴 쪽을 반으로 접음
  - 접기 전 길이가 홀수였다면 접은 후 소수점 이하는 버림
  - 접힌 지폐를 그대로 또는 90도 돌려서 지갑에 넣을 수 있다면 그만 접음
- 지갑에 넣기 위해서 지폐를 최소 몇 번 접어야 하는지 리턴

### 풀이 아이디어
- 지폐를 접는 횟수를 나타내는 정수 변수 answer를 0으로 초기화
- Arrays.sort(wallet) 실행해 오름차순 정렬
- Arrays.sort(bill) 실행해 오름차순 정렬
- bill[0] > wallet[0] || bill[1] > wallet[1]의 조건식을 만족하는 while문 실행
  - bill[1] /= 2 실행해 한 번 접기
  - Arrays.sort(bill) 실행해 다시 오름차순 정렬
  - answer++ 실행
- answer 리턴

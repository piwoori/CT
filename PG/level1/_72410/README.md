# [level1] 신규 아이디 추천 - 72410

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/72410)

### 분류
- 문자열

### 문제 요약
- 신규 유저가 입력한 아이디가 new_id 매개변수
  - new_id는 길이 1 이상 1,000 이하인 문자열
  - new_id는 알파벳 대문자, 알파벳 소문자, 숫자, 특수문자로 구성
  - new_id에 나타날 수 있는 특수문자는 -_.~!@#$%^&*()=+[{]}:?,<>/ 로 한정
- 카카오 아이디의 규칙은 다음과 같은
  - 아이디의 길이는 3자 이상 15자 이하
  - 아이디는 알파벳 소문자, 숫자, 빼기(-), 밑줄(_), 마침표(.) 문자만 사용
  - 단, 마침표(.)는 처음과 끝에 사용할 수 없으며 또한 연속으로 사용할 수 없음
- 다음과 같이 7단계의 순차적인 처리 과정을 통해 신규 유저가 입력한 아이디가 카카오 아이디 규칙에 맞는 지 검사하고 규칙에 맞지 않은 경우 규칙에 맞는 새로운 아이디를 추천
  - 1단계 new_id의 모든 대문자를 대응되는 소문자로 치환
  - 2단계 new_id에서 알파벳 소문자, 숫자, 빼기(-), 밑줄(_), 마침표(.)를 제외한 모든 문자를 제거
  - 3단계 new_id에서 마침표(.)가 2번 이상 연속된 부분을 하나의 마침표(.)로 치환
  - 4단계 new_id에서 마침표(.)가 처음이나 끝에 위치한다면 제거
  - 5단계 new_id가 빈 문자열이라면, new_id에 "a"를 대입
  - 6단계 new_id의 길이가 16자 이상이면, new_id의 첫 15개의 문자를 제외한 나머지 문자들을 모두 제거
    - 만약 제거 후 마침표(.)가 new_id의 끝에 위치한다면 끝에 위치한 마침표(.) 문자를 제거
  - 7단계 new_id의 길이가 2자 이하라면, new_id의 마지막 문자를 new_id의 길이가 3이 될 때까지 반복해서 끝에 붙임
- 7단계의 처리 과정을 거친 후의 추천 아이디 리턴

### 풀이 아이디어
- new_id에 new_id.toLowerCase() 대입
  - 대문자를 소문자로 치환
- new_id에 new_id.replaceAll("[^a-z0-9-_.]", "") 대입
  - a부터 z, 0부터 9, -, _, . 가 아닌 문자들을 ""으로 치환
  - 대괄호 안에서 ^는 그 뒤에 나온 문자가 이닌 문자를 의미
- new_id에 new_id.replaceAll("[.]{2,}", ".") 대입
  - {n,}는 n개 이상을 의미
  - 2개 이상의 . 문자를 "."로 치환
- new_id에 new_id.replaceAll("^[.]|[.]$", "") 대입
  - ^[.]는 문자열 시작의 .을 의미
  - [.]$는 문자열 끝의 .를 의미
  - 이 둘 중에 하나인 문자를 ""으로 치환
- new_id.equals("") 조건식 만족 시
  - new_id에 "a" 대입
- new_id.length() > 15 조건식 만족 시
  - new_id에 new_id.substring(0, 15) 대입
    - 0부터 15 전까지만 추출
  - new_id에 new_id.replaceAll("[.]$", "") 대입
    - 문자열 끝의 .를 의미하는 [.]$를 ""으로 치환
- new_id.length() < 3 조건식을 만족 하는 while문 실행
  - new_id += new_id.charAt(new_id.length() - 1) 실행
- new_id 리턴

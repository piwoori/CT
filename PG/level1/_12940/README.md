# [level1] 최대공약수와 최소공배수 - 12940

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12940)

### 분류
- 최소공배수
- 최대공약수

### 문제 요약
- 자연수 a, b 입력
  - 두 수는 1이상 1000000이하
- 두 수를 입력받아 두 수의 최대공약수와 최소공배수 리턴
- 배열의 맨 앞에 최대공약수, 그다음 최소공배수를 넣어 리턴

### 풀이 아이디어
- 최대공약수를 구하는 함수를 정의하기 위해 정수를 반환하고 정수 a, b를 매개변수로 하는 gcd 메소드 정의
  - b != 0의 조건식을 만족하는 while문 실행
    - 정수 변수 t를 b로 초기화
    - b에 a % b 대입
    - a에 t 대입
  - a 리턴
- 최소공배수를 구하는 함수를 정의하기 위해 정수를 반환하고 정수 a, b를 매개변수로 하는 lcm 메소드 정의
  - a * b / gcd(a, b) 리턴
- 정수 배열을 반환하고 정수 a, b를 매개변수로 하는 solution 매소드 정의
  - 정수 배열 answer를 2 크기로 초기화
  - answer[0]에 gcd(m, n) 대입
  - answer[1]에 lcm(m, n) 대입
  - answer 리턴

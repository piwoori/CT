### 분류
- 반복문

### 문제 요약
- 콜라를 받기 위해 마트에 주어야 하는 병 수 a, 빈 병 a개를 가져다 주면 마트가 주는 콜라 병 수 b, 상빈이가 가지고 있는 빈 병의 개수 n이 매개변수
  - 1 ≤ b < a ≤ n ≤ 1,000,000
- 빈 병 a개를 가져다주면 콜라 b병을 주는 마트가 있을 때, 빈 병 n개를 가져다주면 몇 병을 받을 수 있는지 계산
- 받을 수 있는 콜라의 병 수 리턴

### 풀이 아이디어
- 콜라 병의 수를 나타내는 정수 변수 answer을 0으로 초히과
- n >= a의 조건식을 만족하는 while문 실행
  - 정수 변수 cola를 (n / a) * b로 초기화
  - answer에 cola 더하기
  - n에 다시 cola + (n % a) 대입
- answer 리턴

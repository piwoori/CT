# [level1] 예산 - 12982

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12982)

### 분류
- 배열

### 문제 요약
- 부서별로 신청한 금액이 들어있는 배열 d와 예산 budget 매개변수
  - d는 부서별로 신청한 금액이 들어있는 배열이며, 길이(전체 부서의 개수)는 1 이상 100 이하
  - d의 각 원소는 부서별로 신청한 금액을 나타내며, 부서별 신청 금액은 1 이상 100,000 이하의 자연수
  - budget은 예산을 나타내며, 1 이상 10,000,000 이하의 자연수
- 물품을 구매해 줄 때는 각 부서가 신청한 금액만큼을 모두 지원해 줘야함
- 최대 몇 개의 부서에 물품을 지원할 수 있는지 리턴

### 풀이 아이디어
- 부서의 개수를 나타내는 정수 변수 answer를 0으로 초기화
- 금액의 합을 나타내는 정수 변수 sum을 0으로 초기화
- Arrays.sort(d) 실행해 오름차순 정렬
  - 적은 금액부터 처리해야 더 많은 부서를 지원할 수 있으므로
- 정수 변수 i가 0부터 d.length - 1까지 도는 for문 실행
  - sum += d[i] 실행
  - sum > budget의 조건식 만족 시 break 실행
  - answer++ 실행해 부서 개수 추가
- answer 리턴

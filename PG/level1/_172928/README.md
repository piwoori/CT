# [level1] 공원 산책 - 172928

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/172928)

### 분류
- 이차원 배열

### 문제 요약
- 공원을 나타내는 문자열 배열 park, 로봇 강아지가 수행할 명령이 담긴 문자열 배열 routes 매개변수
  - 3 ≤ park의 길이 ≤ 50
    - 3 ≤ park[i]의 길이 ≤ 50
      - park[i]는 다음 문자들로 이루어져 있으며 시작지점은 하나만 주어짐
        - S : 시작 지점
        - O : 이동 가능한 통로
        - X : 장애물
    - park는 직사각형 모양
  - 1 ≤ routes의 길이 ≤ 50
    - routes의 각 원소는 로봇 강아지가 수행할 명령어를 나타냄
    - 로봇 강아지는 routes의 첫 번째 원소부터 순서대로 명령을 수행
    - routes의 원소는 "op n"과 같은 구조로 이루어져 있으며, op는 이동할 방향, n은 이동할 칸의 수를 의미
      - op는 다음 네 가지중 하나로 이루어져 있음
        - N : 북쪽으로 주어진 칸만큼 이동
        - S : 남쪽으로 주어진 칸만큼 이동
        - W : 서쪽으로 주어진 칸만큼 이동
        - E : 동쪽으로 주어진 칸만큼 이동
      - 1 ≤ n ≤ 9
- 지나다니는 길을 'O', 장애물을 'X'로 나타낸 직사각형 격자 모양의 공원에서 로봇 강아지가 산책을 하려함
- 산책은 로봇 강아지에 미리 입력된 명령에 따라 진행하며, 명령은 ["방향 거리", "방향 거리" … ]과 같은 형식으로 주어짐
- 로봇 강아지는 명령을 수행하기 전에 다음 두 가지를 먼저 확인
  - 주어진 방향으로 이동할 때 공원을 벗어나는지 확인
  - 주어진 방향으로 이동 중 장애물을 만나는지 확인
- 위 두 가지중 어느 하나라도 해당된다면, 로봇 강아지는 해당 명령을 무시하고 다음 명령을 수행
- 공원의 가로 길이가 W, 세로 길이가 H라고 할 때, 공원의 좌측 상단의 좌표는 (0, 0), 우측 하단의 좌표는 (H - 1, W - 1)
- 로봇 강아지가 모든 명령을 수행 후 놓인 위치를 [세로 방향 좌표, 가로 방향 좌표] 순으로 담은 배열 리턴

### 풀이 아이디어
- 공원의 가로 길이를 나타내는 정수 변수 h를 park.length로 초기화
- 공원의 세로 길이를 나타내는 정수 변수 w를 park[0].length()로 초기화
- 로봇 강아지 좌표의 가로, 세로 위치를 나타내는 정수 변수 x와 y를 모두 0으초 초기회
- 정수 변수 i가 0부터 h 전까지 도는 for문 실행
  - 정수 변수 j가 0부터 w 전까지 도는 for문 실행
    - park[i].charAt(j) == 'S' 조건식 만족 시
      - x에 i, y에 j 대입
- 문자열 route가 배열 routes를 도는 for문 실행
  - 명령어를 담을 문자열 배열 parts를 rote.split(" ")으로 초기화
  - 이동 방향을 나타내는 문자열 변수 dir를 parts[0]으로 초기화
  - 총 이동 거리를 나타내는 정수 변수 dist를 Integer.parseInt(parts[1])로 초기화
  - 한 번의 이동 거리의 가로 세로를 나타내는 정수 변수 dx와 dy를 모두 0으로 초기화
  - dir의 switch문 실행
    - case "N"일 때는 dx에 -1 대입
    - case "S"일 때는 dx에 1 대입
    - case "W"일 때는 dy에 -1 대입
    - case "E"일 때는 dy에 1 대입
  - 로봇의 임시 좌표의 가로 세로를 나타내는 정수 변수 nx와 nx를 각각 x와 y로 초기화
  - 공원 범위를 벗어나는지 확인하는 불리언 변수 possible을 true로 초기화
  - 정수 변수 i가 0부터 dist 전까지 도는 for문 실행
    - nx += dx 실행
    - ny += dy 실행
    - nx < 0 || nx >= h || ny < 0 || ny >= w 조건식 만족 시
      - possible에 false 대입
      - break 실행
    - park[nx].charAt(ny) == 'X' 조건식 만족 시
        - possible에 false 대입
        - break 실행
  - possible 조건식 만족 시
    - x에 nx를, y에 ny를 대입
- new int[]{x, y} 리턴

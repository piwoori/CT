# [level1] 명예의 전당 (1) - 138477

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/138477)

### 분류
- PriorityQueue

### 문제 요약
- 명예의 전당 목록의 점수의 개수 k, 1일부터 마지막 날까지 출연한 가수들의 점수인 score 매개변수
  - 3 ≤ k ≤ 100
  - 7 ≤ score의 길이 ≤ 1,000
  - 0 ≤ score[i] ≤ 2,000
- "명예의 전당"이라는 TV 프로그램에서는 매일 1명의 가수가 노래를 부르고, 시청자들의 문자 투표수로 가수에게 점수를 부여
- 지금까지 출연 가수들의 점수 중 상위 k번째 이내이면 해당 가수의 점수를 명예의 전당이라는 목록에 올려 기념
- 프로그램 시작 이후 초기에 k일까지는 모든 출연 가수의 점수가 명예의 전당에 오르게 됨
- 이 프로그램에서는 매일 "명예의 전당"의 최하위 점수를 발표
- 매일 발표된 명예의 전당의 최하위 점수를 담은 배열 리턴

### 풀이 아이디어
- 매일의 최하위 점수를 담을 score.length 크기의 정수 배열 answer 초기화
- 오름차순으로 담기 위한 PriorityQueue<Integer> pq 초기화
- 정수 변수 i가 0부터 score.length 전까지 도는 for문 실행
  - pq.add(score[i]) 실행해 큐에 넣기
  - pq.size() > k의 조건식 만족 시 
    - pq.poll() 실행해 맨 위 원소 꺼내기 + 제거
  - 맨 위 원소를 꺼내 배열에 넣기 위해 answer[i]에 pq.peek() 대입
- answer 리턴

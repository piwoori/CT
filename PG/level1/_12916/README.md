# [level1] 문자열 내 p와 y의 개수 - 12916

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12916)

### 분류
- 문자열

### 문제 요약
- 대문자와 소문자가 섞여있는 문자열 s 매개변수(길이: 50 이하의 자연수)
- 개수를 비교할 때 대문자와 소문자는 구별하지 않음
- s에 'p'의 개수와 'y'의 개수를 비교해 같으면 True, 다르면 False 리턴
- 'p', 'y' 모두 하나도 없는 경우는 항상 True 리턴

### 풀이 아이디어
- 해당 개수를 나타내는 정수 변수 p와 y을 0으로 초기화
- i가 0부터 문자열 s의 길이 -1까지 도는 반복문 실행
  - 문자 변수 c을 s.charAt(i)로 초기화
  - c == 'p' || c == 'P' 조건식을 만족하면 p + 1
  - c == 'y' || c == 'Y' 조건식을 만족하면 y + 1
- p == y면 true 리턴, 아니면 false 리턴

# [level1] 콜라츠 추측 - 12943

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12943)

### 분류
- 정수
- 연산

### 문제 요약
- 콜라츠 추측을 해보고 싶은 정수 num 입력
  - num은 1 이상 8,000,000 미만인 정수
- 콜라츠 추측: 주어진 수가 1이 될 때까지 다음 작업을 반복하면, 모든 수를 1로 만들 수 있다는 추측
  - 1-1. 입력된 수가 짝수라면 2로 나눈다
  - 1-2. 입력된 수가 홀수라면 3을 곱하고 1을 더한다
  - 결과로 나온 수에 같은 작업을 1이 될 때까지 반복한다
- 위 작업을 몇 번이나 반복해야 하는지 리턴
- 주어진 수가 1인 경우에는 0을, 작업을 500번 반복할 때까지 1이 되지 않는다면 –1 리턴

### 풀이 아이디어
- num에 * 3 하면 오버플로우 날 수 있으므로 long 타입 변수 n을 0으로 초기화
- 작업을 몇 번 했는지 나타내는 정수 변수 answer을 0으로 초기화
- n != 1 && answer < 500의 조건식을 만족하는 while문 실행
  - n % 2 == 0 조건식 만족하면 n /= 2 실행
  - 아닐 시 n에 (n * 3) + 1 대입
  - answer++ 실행
- n == 1 ? answer : -1 리턴

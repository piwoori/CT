# [level1] 문자열 나누기 - 140108

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/140108)

### 분류
- 문자열

### 문제 요약
- 문자열 s 매개변수
  - 1 ≤ s의 길이 ≤ 10,000
  - s는 영어 소문자로만 이루어져 있음
- 다음 규칙을 따라서 이 문자열을 여러 문자열로 분해
  - 먼저 첫 글자를 읽습니다. 이 글자를 x라고 함
  - 이제 이 문자열을 왼쪽에서 오른쪽으로 읽어나가면서, x와 x가 아닌 다른 글자들이 나온 횟수를 각각 셈
  - 처음으로 두 횟수가 같아지는 순간 멈추고, 지금까지 읽은 문자열을 분리
  - s에서 분리한 문자열을 빼고 남은 부분에 대해서 이 과정을 반복
  - 남은 부분이 없다면 종료
  - 만약 두 횟수가 다른 상태에서 더 이상 읽을 글자가 없다면, 역시 지금까지 읽은 문자열을 분리하고, 종료
- 위 과정과 같이 문자열들로 분해하고, 분해한 문자열의 개수 리턴

### 풀이 아이디어
- 분해한 문자열의 개수를 나타내는 정수 변수 answer을 0으로 초기화
- x와 같은 문자 개수를 나타내는 정수 변수 same을 0으로 초기화
- x와 다른 문자 개수를 나타내는 정수 변수 diff을 0으로 초기화
- 문자 변수 x를 s.charAt(0)으로 초기화
- 정수 변수 i가 0부터 s.length() 전까지 도는 for문 실행
  - same == diff 조건식 만족 시
    - answer++ 실행
    - x에 s.charAt(i) 대입
    - 다시 same과 diff를 0으로 초기화
  - x == s.charAt(i) 조건식 만족 시
    - same++ 실행
  - 아닐 시
    - diff++ 실행
- answer 리턴

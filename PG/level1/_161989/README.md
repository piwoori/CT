# [level1] 덧칠하기 - 161989

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/161989)

### 분류
- 배열

### 문제 요약
- 페인트가 칠해진 벽의 길이인 정수 n과 롤러의 길이 정수 m과 다시 페인트를 칠하기로 정한 구역들의 번호가 담긴 정수 배열 section 매개변수
  - 1 ≤ m ≤ n ≤ 100,000
  - 1 ≤ section의 길이 ≤ n
    - 1 ≤ section의 원소 ≤ n
    - section에서 같은 원소가 두 번 이상 나타나지 않음
    - section의 원소는 오름차순으로 정렬
- 페인트가 벗겨진 벽이 보기 흉해져 학교는 벽에 페인트를 덧칠
- 넓은 벽 전체에 페인트를 새로 칠하는 대신, 구역을 나누어 일부만 페인트를 새로 칠 함
- 벽을 1미터 길이의 구역 n개로 나누고, 각 구역에 왼쪽부터 순서대로 1번부터 n번까지 번호를 붙임
- 롤러로 벽에 페인트를 한 번 칠하는 규칙은 다음과 같음
  - 롤러가 벽에서 벗어나면 안 됨
  - 구역의 일부분만 포함되도록 칠하면 안 됨
- 한 구역에 페인트를 여러 번 칠해도 되고 다시 칠해야 할 구역이 아닌 곳에 페인트를 칠해도 되지만 다시 칠하기로 정한 구역은 적어도 한 번 페인트칠을 해야 함
- 예산을 아끼기 위해 다시 칠할 구역을 정했듯 마찬가지로 롤러로 페인트칠을 하는 횟수를 최소화
- 롤러로 페인트칠해야 하는 최소 횟수 리턴

### 풀이 아이디어
- 페인트칠을 하는 횟수를 나타내는 정수 변수 answer을 0으로 초기화
- 롤러를 한 번 칠할 때 끝나는 구역의 번호를 나타내는 정수 변수 paintedEnd를 0으로 초기화
- 정수 변수 s가 section을 도는 for문 실행
  - s > paintedEnd의 조건식 만족 시 
    - answer++ 실행
    - paintedEnd에 s + m - 1 대입
- answer 리턴

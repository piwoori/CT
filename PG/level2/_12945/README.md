# [level2] 피보나치 수 - 12945

[문제 링크](https://www.acmicpc.net/problem/12945)

### 분류
- 피보나치

### 문제 요약
- 2 이상 100,000 이하인 자연수 n 매개변수
- 피보나치 수는 F(0) = 0, F(1) = 1일 때 1 이상의 n에 대하여 F(n) = F(n-1) + F(n-2) 가 적용되는 수
- n번째 피보나치 수를 1234567으로 나눈 나머지를 리턴

### 풀이 아이디어
- 정수 prev 변수를 0으로, 정수 cur 변수를 1로 초기화
- i가 2부터 n까지 도는 반복문 실행
- 정수 변수 next를 (prev + cur) % 1234567로 초기화
- prev에 cur를, cur에 next를 대입
- 반복문 종료 후 cur 리턴

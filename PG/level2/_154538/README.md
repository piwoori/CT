# [level2] 숫자 변환하기 - 154538

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/154538)

### 분류
- DP 동적 계획법

### 문제 요약
- 자연수 x, y, n 매개변수
  - 1 ≤ x ≤ y ≤ 1,000,000
    - 1 ≤ n < y
- 자연수 x를 y로 변환하려고 함
- 사용할 수 있는 연산은 다음과 같음
  - x에 n을 더함
  - x에 2를 곱함
  - x에 3을 곱함
- x를 y로 변환하기 위해 필요한 최소 연산 횟수 리턴
- x를 y로 만들 수 없다면 -1 리턴

### 풀이 아이디어
- 각 수의 연산 횟수를 담을 정수 배열 dp를 y + 1 크기로 초기화
- Arrays.fill(dp, -1) 실행 해 -1로 채우기
- dp[x]에 0 대입
- 정수 변수 i가 x부터 y까지 도는 for문 실행
  - dp[i] == -1 조건식 만족 시
    - continue 실행
  - i + n <= y 조건식 만족 시
    - dp[i + n] == -1 조건식 만족 시
      - dp[i + n]에 dp[i] + 1 대입
      - 그 전 숫자에서 한 번 더 연산한 것이기 때문
    - 그 외일 때는
      - dp[i + n]에 Math.min(dp[i + n], dp[i] + 1) 대입
  - i * 2 <= y 조건식 만족 시
    - dp[i * 2] == -1 조건식 만족 시
      - dp[i * 2]에 dp[i] + 1 대입
    - 그 외일 때는
      - dp[i * 2]에 Math.min(dp[i * 2], dp[i] + 1) 대입
  - i * 3 <= y 조건식 만족 시
    - dp[i * 3] == -1 조건식 만족 시
      - dp[i * 3]에 dp[i] + 1 대입
    - 그 외일 때는
      - dp[i * 3]에 Math.min(dp[i * 3], dp[i] + 1) 대입
- dp[y] 리턴

### 문제 요약
- 아이언 슈트 구매자가 이동하려는 거리 N 매개변수(1 이상 10억 이하의 자연수)
- 해당 슈트의 기능:
  - 한 번에 K(1 이상의 자연수) 칸을 앞으로 점프하기
  - 현재까지 온 거리) x 2 에 해당하는 위치로 순간이동 하기
  - 순간이동을 하면 건전지 사용량이 줄지 않음
  - 앞으로 K 칸을 점프하면 K 만큼의 건전지 사용량 소모
- N까지 이동하려고 할 때 사용해야 하는 건전지 사용량의 최솟값 리턴

### 풀이 아이디어
- N이 홀수이면 배터리를 1 사용해야 하고, 짝수면 무료
- 배터리 사용량을 나타내는 정수 변수 answer을 0으로 초기화
- n > 0 이면 반복되는 while문 실행
  - n % 2 == 0 조건식을 만족하면 n /= 2
  - 아니면 n -= 1 한 뒤 answer++

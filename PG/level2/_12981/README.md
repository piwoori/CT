# [level2] 영어 끝말잇기 - 12981

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12981)

### 분류
- Set

### 문제 요약
- 사람의 수 n과 사람들이 순서대로 말한 단어 words 매개변수
  - 끝말잇기에 참여하는 사람의 수 n은 2 이상 10 이하의 자연수
  - words는 끝말잇기에 사용한 단어들이 순서대로 들어있는 배열이며, 길이는 n 이상 100 이하
  - 단어의 길이는 2 이상 50 이하
  - 모든 단어는 알파벳 소문자로만 이루어져 있음
- 영어 끝말잇기는 다음과 같은 규칙으로 진행
  - 1번부터 번호 순서대로 한 사람씩 차례대로 단어를 말함
  - 마지막 사람이 단어를 말한 다음에는 다시 1번부터 시작
  - 앞사람이 말한 단어의 마지막 문자로 시작하는 단어를 말해야 함
  - 이전에 등장했던 단어는 사용할 수 없음 
  - 한 글자인 단어는 인정되지 않음
- 가장 먼저 탈락하는 사람의 번호와 그 사람이 자신의 몇 번째 차례에 탈락하는지 [ 번호, 차례 ] 형태로 리턴
- 주어진 단어들로 탈락자가 생기지 않는다면, [0, 0] 리턴

### 풀이 아이디어
- Set<String> set을 HashSet 구현체로 초기화
- set.add(words[0]) 실행
- 정수 변수 i가 1부터 words.length - 1까지 도는 반복문 실행
  - 문자열 변수 prev을 words[i - 1]로 초기화
  - 문자열 변수 cur를 words[i]로 초기화
  - prev.charAt(prev.length() - 1) != cur.charAt(0) || set.contains(cur)의 조건식를 만족하면
    - 정수 변수 person을 (i % n) + 1로 초기화
    - 정수 변수 turn을 (i / n) + 1로 초기화
    - new int[]{person, turn} 리턴
  - set.add(cur) 실행
- new int[]{0, 0} 리턴

### 분류
- 문자열
- 약수

### 문제 요약
- 10,000 이하의 자연수 자연수 n 매개변수
- 연속된 자연수들로 n을 표현하는 방법의 수 리턴

### 풀이 아이디어
- n을 연속된 자연수의 합으로 나타내는 방법 수 = n의 “홀수 약수 개수”
- 정수 변수 cnt 초기화
- i가 1부터 n까지 2씩 증가하며 도는 반복문 실행
- n % i == 0 이면 cnt++
- 반복문 종료 후 cnt 리턴

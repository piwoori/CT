# [level2] 게임 맵 최단거리 - 1844

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/1844)

### 분류
- 큐

### 문제 요약
- 게임 맵의 상태의 이차원 배열 maps 매개변수
  - maps는 n x m 크기의 게임 맵의 상태가 들어있는 2차원 배열로, n과 m은 각각 1 이상 100 이하의 자연수
  - n과 m은 서로 같을 수도, 다를 수도 있지만, n과 m이 모두 1인 경우는 입력으로 주어지지 않음
  - maps는 0과 1로만 이루어져 있으며, 0은 벽이 있는 자리, 1은 벽이 없는 자리를 나타냄
  - 처음에 캐릭터는 게임 맵의 좌측 상단인 (1, 1) 위치에 있으며, 상대방 진영은 게임 맵의 우측 하단인 (n, m) 위치에 있음
- ROR 게임은 두 팀으로 나누어서 진행하며, 상대 팀 진영을 먼저 파괴하면 이기는 게임
- 각 팀은 상대 팀 진영에 최대한 빨리 도착하는 것이 유리
- 상대 팀이 자신의 팀 진영 주위에 벽을 세워두었다면 상대 팀 진영에 도착하지 못할 수도 있음
- 캐릭터가 상대 팀 진영에 도착하기 위해서 지나가야 하는 칸의 개수의 최솟값 리턴

### 풀이 아이디어
- 맵의 가로 길이를 나타내는 정수 변수 n을 maps.length로 초기화
- 멥의 세로 길이를 나타내는 정수 변수 m을 maps[0].length로 초기화
- 불리언 이차원 배열 visited를 n * m 크기로 초기화
- Queue<int[]> queue를 LinkedList 구현체로 초기화
- queue.offer(new int[]{0, 0, 1}) 실행 해 맨 처음 자리 추가
- visited[0][0]를 true로 초기화
- 정수 배열 dx을 {-1, 1, 0, 0}로 ,정수 배열 dy를 {0, 0, -1, 1}로 초기화
  - 각각 위, 아래, 왼쪽, 오른쪽의 이동을 의미
- !queue.isEmpty()의 조건식의 while문 실행
  - 정수 배열 cur을 queue.poll()로 초기화
  - 왼쪽, 오른쪽으로의 이동을 나타내는 정수 변수 x를 cur[0]로 초기화
  - 위, 아래로의 이동을 나타내는 정수 변수 y를 cur[1]로 초기화
  - 총 움직인 거리를 나태는 정수 변수 dist를 cur[2]로 초기화
  - 최종 목적지의 도착을 의미하는 x == n - 1 && y == m - 1 조건식을 만족하면 dist 리턴
  - 정수 변수 i가 0부터 4 전까지 도는 for문 실행
    - 정수 변수 nx를 x + dx[i]로 초기화
    - 정수 변수 ny를 y + dy[i]로 초기화
    - 맵 크기를 벗어난 nx < 0 || ny < 0 || nx>= n || ny >= m 조건식을 만족하면 continue 실행
    - 이미 방문한 것을 의미하는 visited[nx][ny] 조건식을 만족하면 continue 실행
    - 벽을 의미하는 maps[nx][ny] == 0 조건식을 만족하면 continue 실행
    - visited[nx][ny]에 true 대입
    - queue.offer(new int[]{nx, ny, dist + 1}) 실행
- -1 리턴

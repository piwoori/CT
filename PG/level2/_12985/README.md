# [level2] 예상 대진표 - 12985

### 분류

### 문제 요약
- 게임 참가자 수 N, 참가자 번호 A, 경쟁자 번호 B 매개변수
    - N : 21 이상 220 이하인 자연수
    - 2의 지수 승으로 주어지므로 부전승은 발생하지 않음
    - A, B : N 이하인 자연수 (단, A ≠ B)
- 이 대회는 N명이 참가하고, 토너먼트 형식으로 진행
- N명의 참가자는 각각 1부터 N번을 차례대로 배정받아 1번↔2번, 3번↔4번, ... , N-1번↔N번의 참가자끼리 게임을 진행
- 각 게임에서 이긴 사람은 다음 라운드에 진출
- 게임은 최종 한 명이 남을 때까지 진행
- 음 라운드에서 A번을 가진 참가자는 경쟁자로 생각하는 B번 참가자와 몇 번째 라운드에서 만나는지 리턴

### 풀이 아이디어
- 몇 번째에 만나는지를 나타내는 정수 변수 answer를 0으로 초기화
- a != b의 조건식을 만족하는 while문 실행
    - a에 (a + 1) / 2 대입
    - b에 (b + 1) / 2 대입
    - answer++ 살행
- answer 리턴

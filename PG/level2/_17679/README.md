# [level2] [1차] 프렌즈4블록 - 17679

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/17679)

### 분류
- 이차원 배열

### 문제 요약
- 입력으로 판의 높이 m, 폭 n과 판의 배치 정보 board 매개변수
  - 2 ≦ n, m ≦ 30
  - board는 길이 n인 문자열 m개의 배열로 구성
  - 블록을 나타내는 문자는 대문자 A에서 Z가 사용
- 같은 모양의 카카오프렌즈 블록이 2×2 형태로 4개가 붙어있을 경우 사라지면서 점수를 얻는 게임 실행
- 같은 블록은 여러 2×2에 포함될 수 있으며, 지워지는 조건에 만족하는 2×2 모양이 여러 개 있다면 한꺼번에 지워짐
- 블록이 지워진 후에 위에 있는 블록이 아래로 떨어져 빈 공간을 채우게 됨
- 만약 빈 공간을 채운 후에 다시 2×2 형태로 같은 모양의 블록이 모이면 다시 지워지고 떨어지고를 반복
- 초기 배치의 문자는 라이언(R), 무지(M), 어피치(A), 프로도(F), 네오(N), 튜브(T), 제이지(J), 콘(C)을 의미
- 입력으로 블록의 첫 배치가 주어졌을 때, 지워지는 블록은 모두 몇 개인지 판단하는 프로그램을 제작
- 입력으로 주어진 판 정보를 가지고 지워지는 블록의 개수 리턴

### 풀이 아이디어
- 문자 이차원 배열 map을 m * n 크기로 초기화
- 정수 변수 i가 0부터 m 전까지 도느 for문 실행
  - map[i]에 board[i].toCharArray() 대입
- 지워지는 블록의 개수를 나타내는 정수 변수 answer를 0으로 초기화
- true 조건식을 만족하는 while문 실행
  - 불리언 이차원 배열 remove를 m * n 크기로 초기화
  - 지워지는 블록의 여부를 나타내는 불리언 변수 found를 false로 초기화
  - 2 * 2 블록을 찾기 위해 정수 변수 i가 0부터 m - 1 전까지 도는 for문 실행
    - 정수 변수 j가 0부터  n - 1 전까지 도는 for문 실행
      - 문자 변수 c를 map[i][j]로 초기화
      - c == ' ' 조건식 만족 시
        - continue 실행
      - c == map[i][j + 1] && c == map[i + 1][j] && c == map[i + 1][j + 1] 조건식 만족 시
        - remove[i][j], remove[i][j + 1], remove[i + 1][j], remove[i + 1][j + 1]에 각각 true 대입
        - found에 true 대입
  - !found 조건식 만족 시
    - continue 실행
  - 블록 제거를 위해 정수 변수 i가 0부터 m 전까지 도는 for문 실행
    - 정수 변수 j가 0부터  n 전까지 도는 for문 실행
      - remove[i][j] 조건식 만족 시
        - map[i][j]에 ' ' 대입
        - answer++ 실행
  - 블록 떨어뜨리기를 위해 정수 변수 i가 0부터 m 전까지 도는 for문 실행
    - 정수 변수 bottom를 m - 1로 초기화
    - 정수 변수 j가 0부터  n 전까지 도는 for문 실행
      - map[i][j] != ' ' 조건식 만족 시
        - map[bottom][j]에 map[i][j] 대입
        - bottom != i 조건식 만족 시
          - map[i][j]에 ' ' 대이   
        - bottom-- 실행
- answer 리턴

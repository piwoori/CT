# [level2] 2 x n 타일링 - 12900

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12900)

### 분류
- 배열

### 문제 요약
- 직사각형의 가로의 길이 n 매개변수
  - 가로의 길이 n은 60,000이하의 자연수
- 가로 길이가 2이고 세로의 길이가 1인 직사각형모양의 타일이 있음
- 이 직사각형 타일을 이용하여 세로의 길이가 2이고 가로의 길이가 n인 바닥을 가득 채우려고 함
- 타일을 채울 때는 다음과 같이 2가지 방법이 있음
  - 타일을 가로로 배치 하는 경우
  - 타일을 세로로 배치 하는 경우
-  이 직사각형을 채우는 방법의 수 리턴
  - 경우의 수가 많아 질 수 있으므로, 경우의 수를 1,000,000,007으로 나눈 나머지 리턴

### 풀이 아이디어
- 각 크기 별 경우의 수를 저장할 정수 배열 dp를 n + 1 크기로 초기화
- dp[1]에 1 대입
- n >= 2 조건식 만족 시
  - dp[2]에 2 대입
- 정수 변수 i가 3부터 n까지 도는 for문 실행
  - dp[i]에 (dp[i - 1] + dp[i - 2]) % 1000000007 대입
- dp[n] 리턴

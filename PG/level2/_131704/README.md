# [level2] 택배상자 - 131704

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/131704)

### 분류
- Stack

### 문제 요약
- 택배 기사님이 원하는 상자 순서를 나타내는 정수 배열 order 매개변수
  - 1 ≤ order의 길이 ≤ 1,000,000
  - order는 1이상 order의 길이 이하의 모든 정수가 한번씩 등장
  - order[i]는 기존의 컨테이너 벨트에 order[i]번째 상자를 i+1번째로 트럭에 실어야 함을 의미
- 영재가 실어야 하는 택배상자는 크기가 모두 같으며 1번 상자부터 n번 상자까지 번호가 증가하는 순서대로 컨테이너 벨트에 일렬로 놓여 영재에게 전달
- 컨테이너 벨트는 한 방향으로만 진행이 가능해서 벨트에 놓인 순서대로(1번 상자부터) 상자를 내릴 수 있음
- 컨테이너 벨트에 놓인 순서대로 택배상자를 내려 바로 트럭에 싣게 되면 택배 기사님이 배달하는 순서와 택배상자가 실려 있는 순서가 맞지 않아 배달에 차질이 생김
- 택배 기사님이 미리 알려준 순서에 맞게 영재가 택배상자를 실어야 함
- 만약 컨테이너 벨트의 맨 앞에 놓인 상자가 현재 트럭에 실어야 하는 순서가 아니라면 그 상자를 트럭에 실을 순서가 될 때까지 잠시 보조 컨테이너 벨트에 보관
- 보조 컨테이너 벨트는 앞 뒤로 이동이 가능하지만 입구 외에 다른 면이 막혀 있어서 맨 앞의 상자만 뺄 수 있음
  - 가장 마지막에 보조 컨테이너 벨트에 보관한 상자부터 꺼내게 됨
- 보조 컨테이너 벨트를 이용해도 기사님이 원하는 순서대로 상자를 싣지 못 한다면, 더 이상 상자를 싣지 않음
- 영재가 실을 수 있는 상자의 개수 리턴

### 풀이 아이디어
- 보조 컨테이너를 나타내는 Stack<Integer> stack 초기화
- 메인 컨테이너에서 나오는 상자 번호를 나타내는 정수 변수 current를 1로 초기화
- order에서 현재 실어야 하는 상자의 위치를 나타내는 정수 변수 idx를 0으로 초기화
- current <= order.length 조건식을 만족하는 while문 실행
  - current == order[idx] 조건식 만족 시
    - idx++ 실행
  - 그 외일 때는 stack.push(current) 실행
  - current++ 실행
  - !stack.isEmpty() && idx < order.length && stack.peek() == order[idx] 조건식 만족하는 while문 실행
    - stack.pop() 실행 후
    - idx++ 실행
- idx 리턴
  - 상자를 실을 때마다 정확히 1씩 증가하기 때문에 idx == 지금까지 실은 상자 개수가 됨

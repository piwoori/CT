# [level2] 카펫 - 42842

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/42842)

### 분류
- 약수

### 문제 요약
- 카펫에서 갈색 격자의 수 brown, 노란색 격자의 수 yellow 매개변수
  - 갈색 격자의 수 brown은 8 이상 5,000 이하인 자연수
  - 노란색 격자의 수 yellow는 1 이상 2,000,000 이하인 자연수
  - 카펫의 가로 길이 >= 세로 길이
- 격자 모양 카펫은 중앙에는 노란색으로 칠해져 있고 테두리 1줄은 갈색으로 칠해져 있음
- 카펫의 가로, 세로 크기를 순서대로 담긴 배열 리턴

### 풀이 아이디어
- 2 크기의 정수 배열 arr 초기화
- 1부터 yellow까지 도는 반복문 실행
  - 가로를 나타내는 정수 변수 x를 i + 2로 초기화
  - 세로를 나타내는 정수 변수 y를 (yellow / i) + 2로 초기화
  - (x * y) - yellow == brown && x >= y의 조건식을 만족하면
    - 배열에 각각 대입한 뒤, break으로 반복문 탈출
- arr 리턴
